## 一个我能讲清楚的原理（本人填写）

（例如：断点是什么？Step Over / Step Into 有什么区别？调试器和 print 打印各有什么优劣？）
1.**断点（Breakpoint）**是调试程序时使用的一个标记。它的作用是：**当程序运行到你设置的这一行时，会暂停下来**，让你可以逐步检查程序当时的状态。
2.- **Step Over（跳过 / F10）**：把函数调用**当成一步整体执行**，**不进入**函数内部，直接跳到下一行。
- **Step Into（步入 / F11）**：**钻进函数内部**，从函数的第一行开始逐行执行。
3. 调试器 vs print（打印）优缺点对比：
- 调试器优点：**可以逐行解析代码、随时看变量**，不会留痕迹；缺点：启动慢一点、上手门槛高一点、线上环境不好用
- print 优点：上手难度低、好上手；缺点：没法单独查看某一行执行中的结果、自由度差、容易忘记删

## 遇到的问题（本人填写）

1. **Cursor 里点不出断点红点**：因为 Cursor 默认没装 Python 扩展（之前一直在终端跑代码，没暴露）。解决：装好 Python 扩展。
2. **按 F5 弹选择框，蓝色 "Run and Debug" 按钮按了没反应**：原因是没有指定 Python 解释器。解决：Ctrl+Shift+P → "Python: 选择解释器" → 选全局 python（D:\proflim\python.exe，day24 目录没建 .venv）→ F5 正常。
3. 补充知识：正式项目以后按 F5 还会遇到一次"创建 launch.json"（调试配置文件），建了之后 F5 永远调试当前文件，不再弹窗。
