## 一个我能讲清楚的原理（本人填写）

（例如：POST 和 GET 的区别？headers 有什么用？异常全家桶的各个分支分别在什么时候触发？）
1. **headers 里不能放中文**：==HTTP 头是 1990 年代的"老协议"，只允许 ASCII（英文）字符。把中文写进 headers 会直接报 UnicodeEncodeError；但 json 数据体（请求体）用 UTF-8 编码，可以放中文。记忆口诀：信封上的信息只能用英文写，信纸里的内容什么语言都行==
2. **类方法互相调用必须 self.**：==力扣要求把代码装进 class Solution。类里定义的方法属于对象，递归调用自己必须写 self.climbStairs(...)；写裸的 climbStairs(...) 会 NameError——Python 去全局找这个名字，但类方法不是全局函数==
3. **递归 vs 递推（为什么递归会超时）**：==递归从 n 往下拆，同一个值被反复计算，总量 2ⁿ 爆炸（n=45 约 3.5 万亿次）；递推从 1 往上滚，每个值只算一次，总量 n。递推版用 demo 验证过：f(30) 里 f(3) 被递归算了 30 多万次，递推版只算 1 次==

## 遇到的问题（本人填写）

（卡在哪一步、报了什么错、最后怎么解决的）
==① 网络报错 SSLError(UNEXPECTED_EOF_WHILE_READING)：httpbin.org 直连不稳定。排查：curl 走 Clash 系统代理（7897）能通，但 Python requests 只认环境变量、不认 Windows 系统代理。解决：运行前执行 $env:HTTPS_PROXY / $env:HTTP_PROXY 指向 http://127.0.0.1:7897==
==② 中文 header 报 UnicodeEncodeError（latin-1 编码不了中文）：HTTP 头只允许 ASCII。解决：改成英文 User-Agent: YangKexin-AI-Learner/1.0 和 X-My-Marker: day19，回显确认送达==
==③ 70 题力扣报 NameError：'climbStairs' is not defined——类方法递归忘了 self.。改完又报"超出时间限制"：递归重复计算 2ⁿ 次。解决：改成递推版（a, b = b, a + b 卡片滚动），每阶只算一次，通过==
