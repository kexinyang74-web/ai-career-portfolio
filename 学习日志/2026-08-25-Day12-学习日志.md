## 一个我能讲清楚的原理（本人填写）

> 以下由 Claude 依据实际学习记录代填（用户 2026-08-26 确认）

**双指针为什么是 O(n) 而不是 O(n²)？**——slow 和 fast 各自从数组头走到尾，**每个元素最多被"看"一次、被"写"一次**，没有嵌套循环。对比：如果从前往后一个个找再搬（每次搬动后面所有元素），就是 O(n²)。双指针的价值 = **一趟遍历 + 一个记录位置，把两件事（找 + 放）同时做完**。27/26/88 三道题都是这个思想，只是 slow 的语义随题目变。

## 遇到的问题（本人填写）

> 以下由 Claude 依据实际学习记录代填（用户 2026-08-26 确认）

- `Solution` 未定义 ×3（27/26/35 三题都犯了）：本地写裸函数 `def xxx(nums)`，直接贴网站——网站要求 `class Solution:` 包着、方法名按题目指定（`removeElement`/`removeDuplicates`/`searchInsert`）+ `self` 参数。教训：**直接在网站模板里写，别从本地搬**
- 27 题 `return slow` 缩进在 `if` 里面：第一次遇到非 val 元素就提前返回。教训：return 要等循环全部走完
- 35 题 `nums = [1,3,5,6],`（末尾多逗号）→ 变成元组 → `nums[mid]` 是列表，报 list vs int 不能比较。教训：**逗号 = 元组**，`print(type(nums))` 排查看类型
- `List[int]` 没导入 → `NameError: name 'List' is not defined`（283 题）：类型注解的 `List` 需要 `from typing import List`
- 自测 5 题拼写错：`date.txt`/`data.txt`、`CRITIAL`/`CRITICAL`、`if b ==0` 缺冒号、变量名 `date`/`data` 前后不一致 → NameError
