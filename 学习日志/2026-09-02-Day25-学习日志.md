## 一个我能讲清楚的原理(本人填写)

(例如:pytest 是什么?assert 怎么写?失败输出怎么读?为什么只挂 1 个?)
1.pytest 是 Python 的一个**成熟、功能强大的测试框架**，用来编写和运行单元测试、集成测试和功能测试。
2. assert 语法(模板 + 完整例子):
```python
assert 条件, "失败时显示的提示信息"

def test_add():
    assert 1 + 1 == 2
```

3. 失败输出怎么读（4 步）：
   1. 看 **FAILURES** 下面哪个测试失败
   2. 找 `>` 行：失败代码在哪一行
   3. 看 `E` 行：实际值和期望值分别是什么（左边实际，右边期望）
   4. 看底部总账 `文件::测试函数`，精确定位后修复
4. 为什么只挂 1 个：单个成绩 [5] 只有一轮循环，覆盖（total=5）和累加（0+5）**碰巧结果一样**——不是没出错，是这个测试**没能力发现** bug。测试不是万能的，没走到坏代码的测试永远绿着，所以要写边界用例。
