## 第 2 题：密钥从哪来

骨架启动时密钥是从源码字符串读的，还是从哪里读的？找不到密钥时程序会怎样（你看到的或代码里写的）？

你的答案：
密钥**不是写死在源码字符串里**，而是从环境变量读取。
读不到会报错。
如果找不到密钥，`os.getenv(..., "")` 会让 `API_KEY` 变成空字符串。程序进入 `call_llm()` 后会输出：

```
[错误] 未配置 DEEPSEEK_API_KEY。请复制 .env.example 为 .env 并填入密钥。
```

随后执行：

```
sys.exit(1)
```

也就是**终止程序，并返回错误退出码 1**，
