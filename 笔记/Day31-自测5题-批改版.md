## 第 1 题：记忆在哪

**你的答案：** 把第一轮历史寄回去了；大模型没有记忆。

**批改：✅** 两次 HTTP 彼此独立。所谓记忆 = 你本地的 `messages` 列表。

## 第 2 题：append 顺序

**你的答案：** 先 `assistant`（reply1）再 `user`（新问题）；漏掉后第二次和第一次一样只回复「好」。

**批改：⚠️**

- 顺序：**对**（一轮结束后是 assistant，再追加下一句 user）。
- 「只回复好」：更像是 **两行 append 都没加**，第二次 POST 仍是 `[system, user1]`，所以又生成第一轮那种「好」。
- **只漏 assistant、但仍 append 了第二句 user** 时，列表是 `[system, user1, user2]`。user1 里还有「我叫小周」，模型**仍可能答出名字**，只是角色不完整（两个 user 连着，中间没有助手说过的话）。

## 第 3 题：/new

**你的答案：** history 会清空；费用和窗口两者都有。

**批改：⚠️** 两者都有 ✅。不是空列表，是 **只剩 system 人设**（`history = [system]`）。人设还在，旧的 user/assistant 才丢掉。
