## venv（虚拟环境）三连

```powershell
# 在项目根目录执行
.\.venv\Scripts\Activate.ps1        # ① 激活（成功后命令行开头出现 (.venv)）
pip install -r requirements.txt     # ② 按 requirements.txt 装依赖（install 和 -r 之间有空格！）
pip freeze                          # ③ 看所有已装包（"包==版本"格式）
```

## Git 三件套（检查 AI 的操作）

```powershell
git status          # 现在是什么状态（改了啥、有没有没推送的提交）
git log --oneline   # 最近的提交记录（一行一条）
git diff            # 具体改了什么内容
```

## 密钥安全

```powershell
git check-ignore .env          # ① 检查 .env 是否被忽略（输出 .env = 安全）
git rm --cached .env           # ② 万一已提交：解除 Git 跟踪（磁盘文件保留，不删文件！）
```

- `git status` 里不出现 `.env` = 安全
- 已提交补救两步：`git rm --cached .env`（保留磁盘文件）+ 去 API 平台作废旧密钥、生成新密钥

## 防手滑口诀

- 命令 = **动词 + 空格 + 参数**
- 看到 `unknown command 'xxx'` / `is not a git command` → **先查空格**
- 常见手滑：`install-r`（缺空格）→ `install -r`；`check-ignore.env`（缺空格）→ `check-ignore .env`
