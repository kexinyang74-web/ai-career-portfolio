## 第 3 题：git diff 的符号

- `-` 开头的行：这个代表删减的内容
- `+` 开头的行：这个代表增加的内容
- `@@`：这个我的理解是通过两个这个符号，然后来标注出看他修改了什么内容
- 新文件在 git diff 里看不到的原因：这个我理解是，他那个文件没有被检测到，需要通过一个命令来让它能被检测到。就是这文件是新的就是之前他没有上传过，这是新增的文档就是他之前没有被跟踪过
- 想看新文件的改动用什么命令：`git diff --cached`（或 `--staged`）
