## 第 1 题：读文件（逐行打印）

**你的作答**：

```python
with open("names.txt","r",encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

**批改**：✅ 全对

- ✅ `"r"` 只读模式正确
- ✅ `for line in f` —— 最优雅的逐行遍历方式
- ✅ `line.strip()` —— 脱掉每行自带的换行符，**正是「不要空白行」的解法**
- ✅ 文件名 `names.txt`、统一 4 空格缩进（过程中 `name.txt` 漏 s、Tab/空格混用都自己改对了）

**讲解（为什么必须 `strip()`）**：文件每行末尾**本来就带着一个 `\n`**，而 `print()` 打印完也会自己加一个 `\n`——两个换行叠加 = 多出一行空白。`strip()` 把行首行尾的空白（包括 `\n`）剥掉，`print` 只加自己的那一个，就正好一行一个名字。

## 第 2 题：json 四兄弟（填空）

**你的作答**：

- （1）把字典变成字符串：`json.dumps(user)` → `'{"name": "小明"}'` ✅
- （2）把字符串变回字典：`json.loads('{"name": "小明"}')` ✅
- （3）把字典直接写进文件：`json.dump(user, f)` ✅
- （4）从文件直接读成字典：`data = json.load(f)` ✅
- 一句话记忆：「带 S 的就跟字符串有关」—— ✅ **满分**

**批改**：✅ 全对。记忆口诀精准，一句话把规律说透了。

**讲解**：`s` = **S**tring。带 `s` 的（`dumps`/`loads`）只跟字符串打交道；不带 `s` 的（`dump`/`load`）跟文件打交道。方向记忆：`d` 开头 = 倒出去（写），`l` 开头 = 捞进来（读）。

## 第 3 题：写 JSON 文件

**你的作答**：

```python
import json

student = {"name": "小红", "age": 18, "hobby": ["读书", "跑步"]}

with open("student.json", "w", encoding="utf-8") as f:
    json.dump(student, f, ensure_ascii=False, indent=2)

print("写完了")
```

**批改**：✅ 全对

- ✅ `json.dump`（不带 s）写文件——初版写成了 `dumps` 报 `TypeError`，自己改对了
- ✅ `ensure_ascii=False` —— 中文正常显示，不出现 `\u` 乱码
- ✅ `indent=2` —— 缩进换行，人看得懂
- ✅ `"w"` 模式 + `encoding="utf-8"` 齐全

**讲解**：`dumps` 不认文件参数（`TypeError: takes 1 positional argument`），只有不带 `s` 的 `dump` 才能把数据写进文件。`ensure_ascii=True`（默认）会把中文变成 `小红` 这样的转义码，`False` 才保留中文。

## 第 4 题：读 CSV（跳过表头）

**你的作答**：

```python
import csv

with open("scores.csv", "r", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    next(reader)             # 吃掉第一行表头
    for row in reader:       # 从第二行开始，一行一行来
        print(row)           # 打印每一行
```

**批改**：✅ 全对

- ✅ `next(reader)` —— **「跳过表头」的唯一关键行**，用得很准
- ✅ `newline=""` —— Windows 防空行坑（csv 模块自己加换行，不设这个会多出空行）
- ✅ 遍历打印，注释还写得清清楚楚

**讲解**：`next(reader)` 把流水线的**第一行（表头）单独拿走丢掉**，`for` 自然从第二行开始。没有它，输出会多一行 `['姓名', '语文', '数学']`。

## 第 5 题：综合（函数 + 思考题）

**你的作答**：

```python
import json

def save_user(user_dict, filename):
    with open(filename, "w", encoding="utf-8") as f:
        json.dump(user_dict, f, ensure_ascii=False, indent=2)

# 调用：把数据 + 文件名传进去
save_user({"name": "小明", "age": 20}, "user.json")

# 读回：验证
with open("user.json", "r", encoding="utf-8") as f:
    data = json.load(f)
print(data["name"])
```

**批改**：✅ 代码全对

- ✅ 函数定义、参数 `user_dict`/`filename` 用得很规范（没有写死文件名，函数才通用）
- ✅ 调用按参数顺序传数据、文件名
- ✅ 读回验证 `data["name"]`，输出 `小明`

**思考题批改**：

> 「pen 能保证文件在代码块结束时一定被关闭——即使中途报错也会自动关；而 open + 手动 close 一旦中间出错，close 那行就执行不到，文件会一直占着关不上。」

- ✅ 内容**满分**：说中了两个核心点——① 即使报错也自动关闭；② 手动 close 出错时执行不到
- ⚠️ **1 处笔误**：开头 `pen` 应为 `with`（复制时漏了两个字母）。小问题，修正即可。
