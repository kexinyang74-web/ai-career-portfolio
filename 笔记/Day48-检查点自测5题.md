## 第 2 题：一条命令

陌生人在项目一目录要跑起来，最少哪几步？（venv、`.env`、哪条 python 命令）密钥从哪来、会不会进 git？

你的答案：
最少就是 README「快速开始」那几步：

1. 进项目一目录
2. `python -m venv .venv` → `.\.venv\Scripts\activate`
3. `pip install -r requirements.txt`
4. `Copy-Item .env.example .env`，自己去 DeepSeek 控制台建 key，填进 `.env` 的 `DEEPSEEK_API_KEY`
5. `python main.py`（交互）或 `python main.py "你的提问"`

密钥只在本机 `.env`，不进 git（`.gitignore` 里有 `.env`）。仓库里只有 `.env.example` 模板，没有真 `sk-`
