## 第 1 题：一次请求（核心）

按顺序写一次**非流式** Chat Completions：HTTP 方法与路径、鉴权放哪、body 里最重要的两个字段、成功后文字从 JSON 哪取。

你的答案：
按顺序：

1. **HTTP 方法与路径**

```
POST /chat/completions
```

本项目完整地址默认是：

```
https://api.deepseek.com/chat/completions
```

2. **鉴权放在 HTTP 请求头**

```
Authorization: Bearer 你的_API_KEY
```

3. **JSON body 最重要的两个字段**

```
{
  "model": "deepseek-chat",
  "messages": [
    {"role": "user", "content": "你好"}
  ],
  "stream": false
}
```

其中必须掌握的是：

- `model`：使用哪个模型
- `messages`：交给模型的对话内容

4. **发送请求并等待完整 JSON**

```
response = requests.post(url, headers=headers, json=payload)
data = response.json()
```

5. **从 JSON 中取得模型文字**

```
data["choices"][0]["message"]["content"]
```

整条链路：

```
POST /chat/completions
→ Authorization 放请求头
→ body 放 model 和 messages
→ 等待完整 JSON
→ data["choices"][0]["message"]["content"]
```

## 第 3 题：单轮 / 多轮 / 流式

多轮为什么要把 `assistant` 追加进 `messages`？流式完整回复怎么拼、结束标志是什么？

你的答案：
因为assistant是大模型的回答，不加进去只能看到用户的信息。
流式回复会被拆成许多小片段。代码每收到一个片段，就从这里取文字：

```
json.loads(data)["choices"][0]["delta"]["content"]
```

然后依次放进列表：

```
chunks.append(piece)
```

全部接收完后，用下面这句拼成完整回复：

```
"".join(chunks)
```
 流式结束标志是：

```
data: [DONE]
```
