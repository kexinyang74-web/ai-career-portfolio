# Day 39 同一任务三版 prompt（第 6 周第 4 天）

> 检查点硬任务：**同一句话需求，三版不同 prompt，差异写进日志**。三版必须 **你自己写**，我不代写正文。固定任务如下，这样对比才公平。

## 固定任务（不要改需求本身）

给赛道 **「转行学编程」** 产出 **3 条**选题；每条至少有 **标题** 和 **钩子**。用项目一：

```powershell
cd C:\Users\Administrator\Desktop\学习安排\projects\project-1-ai-assistant
.\.venv\Scripts\activate
python main.py "这里换成你写的第 N 版整段 user"
```

`system_prompt.md` **今天先不要改**（三版只改 user，避免两头一起变）。

## 三版分别拧哪颗螺丝（你写句子）

| 版 | 你要故意做成 | 提示（不是替你写） |
|---|---|---|
| A 糊 | 几乎只有任务半句 | 短、不含格式和例子 |
| B 四件套 | 任务 + 约束 + 格式都写清 | 参考 Day 36 结构指令，条数必须是 3 |
| C 加码 | 在 B 上再加 **few-shot 一条样例** 或 **JSON/三行字段**（二选一，写进这一版） | 参考 Day 37 / 38 |

把 A/B/C 的 **完整 user 原文** 贴进学习日志（不要密钥）。每次跑完用两三句话写：条数对不对、像不像小作文、好不好用。

## 对比时盯什么

- 条数是不是 3
- 有没有标题+钩子
- 有没有被 system 默认「10+3」带跑
- C 比 B 多出来的是形状更稳，还是只是更长

## 做完

答 `笔记/Day39-自测5题.md`（结合你三次真实输出）。不要贴密钥。
