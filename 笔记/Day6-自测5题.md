## 第 4 题：密钥安全（检查点 5）

1. 为什么 `.env` 绝对不能提交到 Git？用一句话说清。
2. 写两条命令，确认 `.env` 没有被跟踪。
3. 如果发现 `.env` 已经进过 Git 历史，完整补救是两步，分别是什么？

作答：
1. 因为这个文件上传到git之后，git会把它同步到远端的仓库，然后你的API密钥就会暴露，容易造成资金的损失
2. git status git log 大概好像是这个，，反正让我写指令，我现在还是不太会
3. 1. `git rm --cached .env` 把 `.env` 从 Git 跟踪里移除（磁盘上的文件保留），并确认 `.gitignore` 里有 `.env`
    2. **去 API 平台换一个新密钥**——旧密钥已经写进 Git 历史，历史删不掉，等于已经"见光"，必须作废
    3. 这两条，我是复制前面笔记的内容，反正让我写这个命令的话，我都不太记得住
