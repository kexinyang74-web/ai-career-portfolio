## 第 2 步：解析——把数据整理成"一行一条"（02_parse.py）

**30 秒知识点**：原始 JSON 是"一个字典装 166 个币种"，但 CSV 是"一行一条数据"的表格。**解析 = 把字典转成行**。

```python
import requests

r = requests.get("https://open.er-api.com/v6/latest/USD", timeout=15)
r.raise_for_status()
data = r.json()

想要 = ["CNY", "JPY", "EUR", "GBP", "KRW", "HKD", "AUD", "CAD"]   # 只留关心的
for 币种 in 想要:
    print(f"1 USD = {data['rates'][币种]} {币种}")
```

**练习**：往 `想要` 里加 2 个你感兴趣的币种（去 https://www.xe.com/ 或搜索"常见货币代码"查代码）。

## 第 3 步：存 CSV（03_save_csv.py）

**30 秒知识点**：Day 11 学过 `csv.writer`，今天复习 + 一个关键参数 `encoding="utf-8-sig"`——**没有它，Excel 打开 CSV 中文会乱码**（utf-8-sig 带 BOM 头，Excel 才能认出编码）。

```python
import csv
import requests

r = requests.get("https://open.er-api.com/v6/latest/USD", timeout=15)
r.raise_for_status()
data = r.json()

想要 = ["CNY", "JPY", "EUR", "GBP", "KRW", "HKD", "AUD", "CAD"]
rows = []                                    # 先收集所有行
for 币种 in 想要:
    rows.append([币种, data["rates"][币种], round(1 / data["rates"][币种], 6)])

with open("汇率.csv", "w", newline="", encoding="utf-8-sig") as f:
    writer = csv.writer(f)
    writer.writerow(["币种", "1 USD 兑换", "1 币种折合 USD"])   # 表头
    writer.writerows(rows)                   # 数据行

print("已保存 汇率.csv，用 Excel 打开看看（应该没有乱码）")
```

**练习**：用 Excel（或记事本）打开生成的 汇率.csv 验证。

## 第 4 步：完整版——函数拆分 + 异常全家桶（04_main.py）

**30 秒知识点**：把前面的代码整理成"一个函数一个职责"，再加异常全家桶——这就是本周检查点验收的"模块化"。

| 函数 | 职责 |
|------|------|
| `fetch_rates()` | 只负责抓数据（返回解析好的字典） |
| `build_rows(data)` | 只负责解析（字典 → 行列表） |
| `save_csv(rows)` | 只负责存文件 |
| `main()` | 组装三兄弟 + 异常处理 |

结构：抓取失败（超时/断网/HTTP 错）时，程序不崩，打印提示。
