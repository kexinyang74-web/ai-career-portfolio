```python
try:
    number = int("100")      # 情况 A：这里能转成功
    # number = int("abc")    # 情况 B：这里会转失败（ValueError）
except ValueError:
    print("① 转换失败")
else:
    print("② 转换成功")
finally:
    print("③ 收尾")
```

- 情况 A（能转成功）的输出是：转换成功 收尾
- 情况 B（转失败）的输出是：转换失败 收尾

一句话总结规律：else 在______时执行，finally 在______时执行。

情况 A（能转成功）的输出是：转换成功 收尾
情况 B（转失败）的输出是：转换失败 收尾
一句话总结规律：else 在没抛异常时执行，finally 在任何情况下执行。
## 第 3 题：防除零（写代码）

写一个函数 `safe_divide(a, b)`：两数相除。如果 `b` 为 0，主动抛出 `ValueError`，提示「除数不能为 0」；否则正常返回结果。调用时用 `try/except` 接住错误并打印提示。请写出完整代码。

作答：
```python
def safe_divide(a,b):
    if b ==0
        raise ValueError(f"除数不能为0")
    return a/b
    
try:
	print(safe_divide(1,2))
	print(safe_divide(1,0))
except ValueError as e:
	print("捕捉到主动抛出的错误：",e)
```
