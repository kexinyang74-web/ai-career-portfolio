## 第 1 题：捕获文件不存在

**你的错误（3 处）**：

| 你写的 | 应该是 | 原因 |
| --- | --- | --- |
| `"date.txt"` | `"data.txt"` | 文件名拼错（date ≠ data） |
| `print(f"{date.txt})` | `print(count)` | f-string 引号没闭合 → SyntaxError |
| `{date.txt}` | `count` | f-string 里只能放变量，`date.txt` 不是变量 |

**参考答案**：

```python
try:
    with open("data.txt", "r", encoding="utf-8") as f:
        content = f.read()
    print(content)
except FileNotFoundError:
    print("⚠️ 文件不存在")
print("程序继续跑，没翻车")
```

**解析**：结构没问题（try 装风险代码 → except 接文件不存在 → 外面收尾）。`print(count)` 或 `print(content)` 直接打印读到的字符串，不需要 f-string。

## 第 2 题：try/except/else/finally 执行顺序 ✅ 全对

- 情况 A（转成功）：`转换成功 收尾`
- 情况 B（转失败）：`转换失败 收尾`
- 规律：**else 在没抛异常时执行，finally 在任何情况下执行**

记忆：else = 成功专属通道；finally = 无条件收尾。

## 第 3 题：防除零

**你的错误（1 处致命）**：`if b ==0` **缺冒号** → `if b == 0:`

**参考答案**：

```python
def safe_divide(a, b):
    if b == 0:                       # 注意冒号！
        raise ValueError("除数不能为0")
    return a / b

try:
    print(safe_divide(1, 2))
    print(safe_divide(1, 0))
except ValueError as e:
    print("捕捉到主动抛出的错误：", e)
```

**解析**：`if` 语句结尾必须有冒号，漏了直接 SyntaxError。`raise ValueError("...")` 不需要 f 前缀（没有占位符）。

## 第 5 题：综合（JSON + 防护 + 日志）

**你的错误（1 处致命）**：`date = json.load(f)` 与 `data["name"]` —— **变量名前后不一致** → NameError。

**参考答案**：

```python
import json
import logging

logging.basicConfig(
    filename="app.log",
    level=logging.INFO,
    format="%(asctime)s | %(levelname)s | %(message)s"
)

logging.info("开始读取 user.json")

try:
    with open("user.json", "r", encoding="utf-8") as f:
        data = json.load(f)          # 注意：data（数据的 data）
except FileNotFoundError:
    print("user.json 不存在，请检查文件")
    logging.error("user.json 不存在")
except json.JSONDecodeError as e:
    print("user.json 内容损坏，不是合法的JSON")
    logging.error(f"user.json 内容损坏：{e}")
else:
    print(data["name"])
    logging.info("读取成功")
```

**解析**：整体结构满分（import → basicConfig → 开始日志 → try → 两种 except → else 收尾）。唯一问题：变量定义和使用必须**同名**。
