## 一、核心要点（一页速记）

- venv = **项目独立小房间**：每个项目一个专属的 Python + 包环境，避免依赖打架；全局 Python = **公共大厅**，所有项目共用
- 激活（在项目根目录）：`.\.venv\Scripts\Activate.ps1`（激活后命令行开头出现 `(.venv)`）；装依赖 `pip install -r requirements.txt`；看包 `pip list` / `pip freeze`
- `.env` 格式：一行一个 `变量名=值`，**等号两边无空格**，**值不加引号**，`#` 开头是注释
- 读取：`load_dotenv()` 把 `.env` 读进来 → `os.getenv("变量名")` 取值
- 防泄露：`.env` 写进 `.gitignore`；用 `git status`（不显示）和 `git check-ignore .env`（有输出 = 已忽略）确认；万一已提交 → 移除跟踪 + 去平台换新密钥
