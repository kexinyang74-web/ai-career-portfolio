# Day 47 STAR 初稿（第 7 周第 5 天）

> 项目一简历描述 **必须你自己写**。规格书提示句可以当方向，**不能照抄还写「错误重试」**——你本周没做自动重试。不要编播放量、用户数、准确率。

STAR 四格（各写 2～5 句即可）：

| 格        | 问什么      | 用你做过的事实                                                             |
| -------- | -------- | ------------------------------------------------------------------- |
| **S 情境** | 谁、什么问题   | 例如：给自己做 B站选题助手，不要套壳网页                                               |
| **T 任务** | 你要交付什么   | 命令行可跑、人设、多轮、能演示                                                     |
| **A 行动** | 你具体做了哪几步 | DeepSeek API、`system_prompt.md`、四件套、`/new` `/stream` `/save`、`.env` |
| **R 结果** | 现在能怎样    | `python main.py` 一条命令；三种场景（选题/追问/口播）；有 README 和出选题录屏。没做的不要写         |

可写在学习日志「STAR 初稿」或 `笔记/项目一-STAR初稿.md`。数字只用真实的（3 条场景、本地能跑），没有的指标就空着。

规格那句「支持流式输出与错误重试」：流式你有（`/stream`）；重试你没有，写成「超时/失败会提示并退出」或干脆不提重试。
