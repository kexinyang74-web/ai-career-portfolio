## 第 1 题：为什么是 POST

**你的答案：** POST 是提交输入并生成新结果，GET 是读现成资源；body 不能缺 `model`、`messages`。

**批改：✅** GET 把参数挂在 URL 上，对话太长也不适合；密钥更不该出现在 URL 里。`model` + `messages` 选对了。

## 第 2 题：鉴权

**你的答案：** `Authorization: Bearer YOUR_API_KEY`；写进源码会泄漏、被盗用、花钱。

**批改：✅** 格式就是 `Bearer` + 空格 + 密钥（从 `.env` 读，不要抄进 py）。再加一条：源码会进 git，密钥进仓库等于公开。

## 第 4 题：401 和超时

**你的答案：** 401 查密钥（错/没粘全/空格）；timeout 防止长时间不响应；SSL「把报错放在前面」。

**批改：⚠️**

- 401、timeout 前半：**对**。`timeout=120` 更准确是：最多等 120 秒，到点就放弃，避免程序一直挂着（模型慢时这 120 秒是留给它生成的）。
- 第 3 问 **理解偏了**。题目问的是 Day 19 那种 **SSL/连不上** 时先试哪招，不是代码里 except 的书写顺序。先设：

```powershell
$env:HTTPS_PROXY = "http://127.0.0.1:7897"
```

再重跑。

## 第 5 题：usage

**你的答案：** prompt = 用户输入；completion = 模型产出；21、22、43。

**批改：⚠️**（数字 ✅）

三个数和终端一致：21 + 22 = 43。  
`completion_tokens` 对。  
`prompt_tokens` **不只是用户那一句**——你发出去的整份 `messages`（含 system）都算 prompt。你这次 system + user 一共 21。
