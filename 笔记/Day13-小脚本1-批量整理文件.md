## 第 1 步：遍历文件夹，认识每个文件（02_scan_files.py）

**30 秒知识点**：上一段你看到了 `iterdir()` 列出所有条目。但真实的文件夹里可能还有**子文件夹**——这时候要用 `rglob("*")`（r = recursive 递归，把子文件夹里的也挖出来）。

**动手**（新建 `02_scan_files.py`）：

```python
# 第 1 步：遍历文件夹
import pathlib

folder = pathlib.Path("test_files")

for file in folder.rglob("*"):          # 递归遍历所有文件
    if file.is_file():                   # 是文件（不是文件夹）才处理
        print(f"名字：{file.name}｜后缀：{file.suffix}｜父文件夹：{file.parent}")
```

**要能讲明白**：
- `file.name` = 文件名（含后缀）
- `file.suffix` = 后缀（`.jpg` 这种，**没有后缀的返回空字符串**）
- `file.parent` = 它所在的文件夹
- `is_file()` = 判断是不是文件（文件夹返回 False，跳过）

## 第 2 步：按后缀分类归档（03_organize.py）——小脚本的核心

**30 秒知识点**：归档 = 给每个类型建一个文件夹（图片/文档/压缩包/其他），把文件**移动**进去。移动用 `Path.rename()`——注意，路径对象改名 = 移动！

**动手**（新建 `03_organize.py`）：

```python
# 第 2 步：按后缀分类归档
import pathlib

folder = pathlib.Path("test_files")
# 分类规则：后缀 → 目标文件夹名（这就是"规则"，你想怎么定就怎么定）
RULES = {
    ".jpg": "图片",
    ".png": "图片",
    ".txt": "文档",
    ".pdf": "文档",
    ".docx": "文档",
    ".zip": "压缩包",
    ".mp4": "视频",
}

for file in folder.rglob("*"):
    if not file.is_file():
        continue                        # 不是文件就跳过（continue = 这轮不干，下一轮）

    target_dir = RULES.get(file.suffix, "其他")   # get(键, 默认值)：没匹配到就归"其他"
    dest = folder / target_dir / file.name        # 目标路径 = 分类文件夹 / 文件名
    dest.parent.mkdir(exist_ok=True)              # 先建分类文件夹（存在也不报错）

    file.rename(dest)                             # 移动文件（rename = 改名/搬家）
    print(f"移动：{file.name} → {target_dir}/")
```

**要能讲明白**：
- `RULES.get(file.suffix, "其他")`：字典的 `get` 方法——有这个键返回对应值，**没有就返回默认值**"其他"（第 10 天学的字典，今天用上了）
- `dest.parent.mkdir(exist_ok=True)`：先建目标文件夹。`exist_ok=True` = 已经存在也不报错（第 11 天学的容错思想）
- `file.rename(dest)`：**移动**。文件从一个路径"改名"到另一个路径 = 换了个地方 = 移动

## 第 3 步：重命名（加序号）——进阶功能（04_rename.py）

**30 秒知识点**：`file.rename()` 不仅能让文件搬家，还能**在同一个文件夹里改名**。重命名的常见需求：加序号（01、02、03……）保证顺序不乱。

**动手**（新建 `04_rename.py`，在 `03_organize.py` 基础上改造）：

```python
# 第 3 步：给分类后的文件加序号重命名
import pathlib

folder = pathlib.Path("test_files")

for sub in folder.iterdir():                  # 遍历分类子文件夹
    if not sub.is_dir():                      # 只看文件夹（分类目录）
        continue
    for i, file in enumerate(sub.iterdir(), start=1):   # start=1：序号从 1 开始
        new_name = f"{i:02d}_{file.stem}{file.suffix}"  # 02d = 两位数（01、02…）
        new_path = file.with_name(new_name)             # 换名字不换位置
        file.rename(new_path)
        print(f"改名：{file.name} → {new_name}")
```

**要能讲明白**：
- `enumerate(sub.iterdir(), start=1)`：遍历时顺便给序号（第 9 天学的 enumerate，今天用上）
- `f"{i:02d}"`：`02d` 表示"至少两位数字，不够前面补 0"→ 1 变 `01`，10 变 `10`（否则排序会乱：10 排在 2 前面）
- `file.stem` = 文件名**去掉后缀**的部分（`风景照.jpg` → `风景照`）
- `file.with_name(新名字)` = 同文件夹下换个名字（和 `folder / 新名字` 效果一样，更省事）

## 第 4 步：加日志 + 防出错——变成"真脚本"（05_final.py，完整版）

**30 秒知识点**：现在把所有招式合体——昨天学的 `logging`（记日志）+ `try/except`（防出错）加进来，脚本才算"能见人"。

**动手**（新建 `05_final.py`，把前 3 步合起来，加上防护）：

```python
# 第 4 步：完整版——归档 + 重命名 + 日志 + 防错
import logging
import pathlib

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s | %(levelname)s | %(message)s",
    filename="organize.log",          # 日志写进文件（昨天的知识！）
)

RULES = {".jpg": "图片", ".png": "图片", ".txt": "文档", ".pdf": "文档",
         ".docx": "文档", ".zip": "压缩包", ".mp4": "视频"}

folder = pathlib.Path("test_files")

def organize():
    logging.info(f"开始整理：{folder}")
    for file in folder.rglob("*"):
        if not file.is_file():
            continue
        target_dir = RULES.get(file.suffix, "其他")
        dest = folder / target_dir / file.name
        try:
            dest.parent.mkdir(exist_ok=True)
            file.rename(dest)
            logging.info(f"归档：{file.name} → {target_dir}/")
        except OSError as e:
            logging.error(f"处理 {file.name} 失败：{e}")     # 出错不翻车，记下来继续

if __name__ == "__main__":
    organize()
    logging.info("整理完成")
    print("整理完成，日志见 organize.log")
```

**要能讲明白**：
- `if __name__ == "__main__":` —— 意思是"**只有直接运行这个文件时**才执行下面的代码"（被别的文件 import 时不会执行）。职业脚本的标准写法，先照抄记住
- `except OSError as e`：文件操作类错误（权限不够、文件被占用……）都属于 OSError，接住它，记日志，**继续处理下一个**——这就是"不翻车"脚本的样子
