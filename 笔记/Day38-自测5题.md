## 第 3 题：根必须是对象

如果模型直接输出 `[ {...}, {...} ]` 这种顶层数组，JSON 模式有时会失败。今天脚本为什么要求包在一个对象里（例如 `{"items":[...]}`）？

你的答案：
今天脚本要求包一层对象，就是让输出与 `json_object` 的要求保持一致，也让后续代码能统一通过 `data["items"]` 取出列表，避免顶层类型不一致导致失败。

**这层包装解决的是结构兼容和读取方式，不代表里面的内容更准确、写得更好。**

## 第 4 题：解析失败你先看哪

打印出来的字符串 `json.loads` 报错时，你先怀疑 prompt 没要 JSON，还是模型在 JSON 外加了说明文字？

你的答案：
我会**先检查原始字符串是否在 JSON 外加了说明文字或 Markdown 代码围栏**，而不是直接认定 prompt 没要求 JSON。

用 `print(repr(raw))` 查看完整原文，再结合 `json.loads` 的报错位置判断，也可能是输出被截断或字符串为空。

如果确实启用了 `json_object`，JSON 外出现说明文字并不正常，应检查模式是否生效；缺少 JSON 指令通常会在请求阶段报错。
