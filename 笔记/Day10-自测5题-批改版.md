## 第 1 题：列表增删改查

**你的作答**：

```python
nums = [1,2,3]
nums.append(4)
nums[0] = 10
nums.remove(2)
print(nums)
print(len(nums))
```

**批改**：

- ✅ ① `append(4)` 加末尾正确
- ⚠️ ② **索引 1 是第二个元素**（索引从 0 数起），你写成了 `nums[0] = 10`（改的是第一个元素）。应为 `nums[1] = 10`。
- ✅ ③ `remove(2)` 删值正确
- ✅ ④ 打印 + `len()` 正确

**讲解（为什么你的代码能跑通）**：严格按题目顺序（先改索引 1 → 再删值 2）会报 `ValueError`——因为索引 1 的 `2` 已经被改成 `10`，`remove(2)` 找不到它了。你的写法恰好改的是索引 0，`2` 还在，所以没报错。**教训：改值前先想清楚"此刻列表里这个位置是谁"**。

**正解（调换顺序，让三个操作都成立）**：

```python
nums = [1, 2, 3]
nums.append(4)      # [1, 2, 3, 4]
nums.remove(2)      # [1, 3, 4]（先删 2）
nums[1] = 10        # [1, 10, 4]（索引 1 是 3，改成 10）
print(nums)         # [1, 10, 4]
print(len(nums))    # 3
```

## 第 2 题：字典增删改查

**你的作答**：

```python
user = {"name": "小明", "age": 20}
print(user["name"])
user["city"] = 北京
user["age"] = 21
user.pop("city")
print(user.get("score", "没有这个键"))
```

**批改**：

- ✅ ① 打印 name 正确 ｜ ✅ ③ 改 age 正确 ｜ ✅ ④ pop 删 city 正确 ｜ ✅ ⑤ `get` 带默认值用得标准
- ⚠️ ② `user["city"] = 北京` —— **`北京` 没加引号**！Python 会把 `北京` 当成变量名，运行到这报 `NameError: name '北京' is not defined`。字符串必须用引号包起来。

**正解**：

```python
user["city"] = "北京"   # 引号！
```

## 第 3 题：元组 vs 列表

**你的作答**：

```python
point = (10, 20)
point[0] = 99
lst = list(point)
# 一句话：元组就是不可变，当需要用到不可变的元素的时候，就用元组，比如把它放在字典里面
```

**批改**：

- ✅ 全对！`point[0] = 99` 会报 `TypeError: 'tuple' object does not support item assignment`——正是要验证的"元组不能改"
- ✅ `list(point)` 转列表正确
- ✅ 一句话回答**满分**："不可变 + 能放字典里"——还说出了元组能当字典键这个进阶知识点

**小建议**：`point[0] = 99` 这行是故意报错的，可以加个注释标明，免得以后自己看代码以为写错了：

```python
point[0] = 99   # 故意报错验证：TypeError（元组不可变）
```

## 第 4 题：集合去重

**你的作答**：

```python
unique = list(set(words))
print(words)
```

**批改**：

- ✅ `unique = list(set(words))` 去重套路正确
- ⚠️ `print(words)` 打印的是**原列表**（还没去重的那份）！题目要求打印去重结果 + `"apple" in 去重后` 的判断。

**正解**：

```python
words = ["apple", "banana", "apple", "orange", "banana"]
unique = list(set(words))
print(unique)                 # 去重结果，如 ['apple', 'banana', 'orange']
print("apple" in unique)      # True
```

## 第 5 题：综合（count_char）

**你的作答**：

```python
def count_char(text):
    char = {}
    for word in text.split():
        char[word] = char.get(word,0) +1
    return char

print(count_char("hello"))
```

**批改**：

- ✅ 字典统计的思路完全正确
- ⚠️ 切错了单位：题目要求统计**每个字符**，而 `text.split()` 是按空白切**单词**。`"hello"` 没有空格 → 整个当一个单词 → 输出 `{'hello': 1}`，不是期望的 `{'h':1,'e':1,'l':2,'o':1}`。

**讲解**：字符串可以**直接遍历每个字符**，根本不需要 `split()`：

```python
for ch in text:      # 字符串直接遍历 = 一个一个字符
```

**正解**：

```python
def count_char(text):
    char = {}
    for ch in text:                 # 字符，不是单词
        char[ch] = char.get(ch, 0) + 1
    return char

print(count_char("hello"))   # {'h': 1, 'e': 1, 'l': 2, 'o': 1}
```
