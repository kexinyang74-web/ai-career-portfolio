# Day 9｜Pydantic 模型 + 内存存储：写「创建」与「查全部」

日期：2026-10-10

> 第 2 周第二天。今天在 Day 8 已经跑通的 `projects/fastapi-practice/` 上加两样东西：**一个 Pydantic 模型**（数据长什么样、什么算合法）和**一个内存存储**（一个 dict，先不接数据库），然后写两个接口：**创建** `POST` 和 **查全部** `GET`。

## 今天的目标

从"只有一个固定返回的 `GET /health`"，走到"**能往服务里塞进一条数据，再把它列出来**"。这是本周四个接口里的前两个，也是"存储"这一层第一次真正出现。

## 今天不做

- 不接数据库（SQLite 是**下周**的事），存储就用**内存里的一个 dict**。
- 不写「查单个 / 修改 / 删除」——那是 Day 10 以后。
- 不让 AI 生成完整函数或项目骨架（AI 只提示、指错、说下一步）。
- 不复制 `media-topic-assistant` 的代码，可以看它的结构。

## 今天的四个新概念（先认字，再动手）

| 词 | 一句话 |
|---|---|
| **Pydantic 模型** | 用一个类描述"一条数据应该长什么样"，FastAPI 用它**自动校验**客户端传来的东西。 |
| **请求体（body）** | `POST` 时客户端发过来的那份 JSON。 |
| **内存存储** | 一个进程级的 `dict`，程序一重启就清空。今天用它代替数据库。 |
| **路径 / 状态码** | `POST /items` 建一条；建成功默认返回 `200`（想更准确可用 `201`）。 |

### 第 1 步：想清"一条数据长什么样"
今天做一个最普通的资源，就叫 `item`（条目）。先**只用中文写**（不查资料）：一条 item 至少要有哪几个字段？哪些是客户端**必须**给的，哪些可以**自动生成**？

> 提示：想想"新建一条记录"——用户会告诉你什么？id 该由谁来定？

把这段想清楚写在本子上，再往下。

### 第 2 步：加 Pydantic 模型
在 `main.py` 里，用 `from pydantic import BaseModel` 定义一个描述 item 的类。

- 名字你定（如 `ItemCreate` 或 `Item`）。
- 必须字段用类型标注写清（如 `name: str`）；
- 一个可选字段怎么标（`price: float | None = None`）——想不起来标 `# 想不起来：……`。

> **只问自己一句**：这个类定义了以后，FastAPI 会**拿它去挡什么**？（这题 Day 14 检查点会问你。）

### 第 3 步：加内存存储
在模块顶层建一个 dict（如 `items: dict[int, ...] = {}`）和一个**自增 id 计数器**（如 `next_id = 1`）。

- 想清楚：**为什么 id 由服务端生成，而不是让客户端传？**
- 想清楚：这个 dict 放在**函数外**还是**函数内**？如果放在某个接口函数里，会发生什么？（这是今天的坑点之一，先写预测。）

### 第 4 步：写「创建」`POST /items`
写一个 `@app.post("/items")` 的函数，接收第 2 步那个模型作为参数（FastAPI 会自动把请求体转成这个对象）。

函数体里至少要做三件事：
1. 用当前计数生成一个新 id；
2. 把这条数据**存进 dict**；
3. **返回**存进去的这条（让调用方知道 id 是多少）。

> 卡在"怎么接收请求体 / 怎么知道客户端传了什么"时，先猜，再问一句"错在哪 / 下一步想什么"。

### 第 5 步：写「查全部」`GET /items`
写一个 `@app.get("/items")` 的函数，把 dict 里所有条目返回回去（如 `return list(items.values())`）。

- 想清楚：**空 dict 时它返回什么**？先写预测。

### 第 6 步：在 /docs 里调通（验收证据）
1. 先 `GET /items` → 预期返回空列表 `[]`；
2. `POST /items` 发一条 `{"name": "..."}` → 看返回里有没有 `id`、状态码是多少；
3. 再 `GET /items` → 预期里面有你刚建的那条；
4. **故意发一条坏数据**（比如漏掉必填字段，或把 `price` 传成字符串）→ **记下状态码**（应该是 `422`，不是 500），把返回原文记在本子上。

### 第 7 步：对一遍"五层"（重点 = 补 #2）

- **路由**：哪一行？  @app.post("/items")

- **存储**：存在哪？为什么重启就没了？data，内存中，
