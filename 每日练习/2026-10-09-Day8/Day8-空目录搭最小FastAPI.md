# Day 8｜从空目录搭最小 FastAPI

日期：2026-10-09

> 第 2 周第一天。今天只做一件事：**从空目录自己搭出一个能跑的 FastAPI 服务，写第一个接口，用 `/docs` 调通。**

## 今天的目标

让"空目录 → 能跑的 API"这条路，你自己走一遍。第 1 周你读的是**别人的项目**；从今天起是**自己搭**。

## 今天不做

- 不抄 `media-topic-assistant` 的代码（可以看结构，**代码自己敲**）。
- 不接数据库、不加增删改查——今天**只做一个 GET**。
- 不让 AI 生成整段代码（AI 只提示、指错、说下一步）。

## 任务流程

### 第 0 步：建目录和环境
在 `学习安排\projects\` 下建一个新文件夹（名字你定，比如 `fastapi-practice`），里面建虚拟环境、装依赖：

```powershell
cd 你的新目录
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install fastapi "uvicorn[standard]"
```

记录：建在哪、装了什么。

### 第 1 步：写第一个接口

新建 `main.py`，凭第 1 周的理解写出：

- 一个 `FastAPI()` 实例；
- 一个 `@app.get("/health")` 路由，返回一个字典（比如 `{"status": "ok"}`）。

> 别抄旧项目——先想"我记得的 FastAPI 最小骨架长什么样"。写不出就在原地标 `# 想不起来：……`，继续写下一行。

### 第 2 步：跑起来

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

- 看终端打印的地址；浏览器打开 `http://127.0.0.1:8000/docs`。
- 在 `/docs` 里点开你的 `/health`，Try it out，看返回。

### 第 3 步：对一遍"五层"（今天有哪几层）

今天的接口很薄，但先对一遍：

- **路由**：哪一行？
- **参数**：今天有没有？
- **业务**：函数体里做了什么？
- **存储**：今天有没有？
- **返回值**：返回了什么、被谁转成 JSON？

### 第 4 步：收尾

- 三栏学习日志（**本人写**，见 `2026-10-09-学习日志.md`）。
- 5 题自测（**本人答**，见 [[Day8-自测5题]]）。

## 卡住时怎么问

贴：**你写的那几行 + 完整报错原文 + 你以为会怎样**。只问"错在哪一行 / 下一步想什么"，不要完整代码。
