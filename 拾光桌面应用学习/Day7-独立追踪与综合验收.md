## 可撤销的小改动

选择一个不改变正式接口的改动，例如调整学习副本中的一段提示文字：

1. 在日志里先写“我预计改哪个文件、页面会发生什么变化”。
2. 运行 `git status --short`。
3. 完成一个最小改动。
4. 运行与该文件相关的检查，再运行 `npm run check`。
5. 使用 `git diff` 判断实际变化是否符合预期。
6. 保留差异等待自己验收，不提交、不推送。
