# 拾光桌面应用：一周源码学习路线

## 目标

用 7 天、每天约 2 小时，读懂一条真实的桌面应用数据链路：

`Svelte 页面 → JavaScript 封装 → Tauri invoke → Rust command → SQLite → 返回页面`

主线是“素材库保存笔记”，第 6～7 天用“学习问答”验证能否迁移所学。

## 使用方式

1. 每天先打开对应的 `DayN-*.md`，不要一次读完全部源码。
2. 遇到“先预测”时先写下预测，再运行命令。
3. 自测题没有答案；把回答写在题目下方，再交给 Codex 批改。
4. “遇到的问题、自己的原理解释、还没搞懂的部分”必须自己填写。
5. 每次源码实验前运行 `git status --short`，实验后运行 `git diff`。

## 每天固定节奏

- 10 分钟：复习与写问题
- 25 分钟：概念学习
- 45 分钟：源码追踪
- 25 分钟：运行或小实验
- 10 分钟：5 道自测
- 5 分钟：学习日志

## 常用命令

```powershell
cd "C:\Users\Administrator\Documents\Codex\2026-09-25\ai\outputs\shiguang-desktop-learning"
npm install

cargo test --manifest-path src-tauri/Cargo.toml --test storage_test

git status --short

```

第一次安装依赖需要网络。真实 DeepSeek、TikHub、百炼密钥不是本课程前提。
