# 面试题记录模板

每天 1-2 道，按分类积累。面试前一周只复习自己的错题本。

## 记录格式

| 分类 | 题目 | 我的答案（先自己答） | 参考答案/标准答法 | 来源 | 掌握程度 |
|------|------|---------------------|-------------------|------|---------|
|  |  |  |  |  | 未掌握/一般/熟练 |

## 起步题库（20 题，第 17 周前刷完）

### Python（5 题）
1. 列表和元组的区别？什么时候用哪个？
2. 什么是装饰器？写一个计时装饰器。
3. GIL 是什么？多线程为什么不能并行计算？
4. 生成器与迭代器的区别？yield 的作用？
5. 浅拷贝和深拷贝的区别？

### LLM 基础（5 题）
6. 什么是 token？上下文窗口超了怎么办？
7. temperature 和 top_p 分别控制什么？
8. 大模型为什么会"幻觉"？怎么缓解？
9. Function Calling 的原理是什么？模型怎么决定调用哪个工具？
10. 什么是结构化输出？如何保证返回合法 JSON？

### RAG（4 题）
11. RAG 解决什么问题？完整流程讲一遍。
12. 为什么 RAG 能减少幻觉？什么时候会失效？
13. 文档切分有哪些策略？对检索效果有什么影响？
14. Embedding 是什么？怎么评估检索质量？

### Agent（3 题）
15. 什么是 ReAct 模式？Agent 循环里状态怎么流转？
16. 多 Agent 协作和单 Agent 的取舍？
17. MCP 是什么？解决了什么问题？

### 工程（3 题）
18. API 服务的限流怎么做？为什么需要？
19. Docker 和虚拟机的区别？镜像和容器的关系？
20. 线上服务报错了怎么排查？讲一下你的排查思路。

## 项目深挖必问题（每个项目都要准备）

- 这个项目你独立完成的部分是什么？
- 最难的问题是什么？怎么解决的？
- 为什么选这个技术方案？还有别的选择吗？
- 如果数据量扩大 100 倍，哪里会先崩？
- 你的回答准确率怎么测的？评测集怎么来的？
