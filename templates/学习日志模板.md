# 学习日志模板

每天一篇，推送到 GitHub。**面试官翻你的仓库，学习日志是最直观的"坚持"证据。**

## 填写格式

```markdown
# YYYY-MM-DD 学习日志

## 今天做了什么
- （学到的知识点 / 写的代码 / 解决的问题）

## 今天写的代码
- 文件：xxx.py
- 完成的功能 / 遇到的问题 / 如何解决的

## 一个我能讲清楚的原理
- （今天最重要的概念，用自己的话解释，像讲给小白听）

## 遗留问题
- （没搞懂的地方，下次解决）

## 明日计划
- （1-3 件事）
```

## 示例（填好的样子）

```markdown
# 2026-08-19 学习日志

## 今天做了什么
- 用 requests 完成了第一次 DeepSeek API 调用
- 理解了 token 和 temperature 对输出的影响

## 今天写的代码
- 文件：call_llm.py
- 问题：返回结果被截断 → 发现需要设置 max_tokens
- 解决：在请求参数中加入 max_tokens=2000

## 一个我能讲清楚的原理
token 是模型处理文本的最小单位。一次 API 请求 = 把 messages 编码成 token 发给模型，
模型生成新的 token 返回，再解码成文字。上下文窗口就是一次请求最多能容纳的 token 数。

## 遗留问题
- 流式输出和普通输出的区别还没完全理解

## 明日计划
- 学习流式输出
- 完成项目一骨架改造
```

## 写作要求

- 每天 30-60 分钟，不追求长，追求"能用自己的话讲清楚"
- 代码要真的跑过、贴真实输出，不贴没验证的代码
- 每周日把 7 篇日志归档到 `notes/week-NN/` 目录
