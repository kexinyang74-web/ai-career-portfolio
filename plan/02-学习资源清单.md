# 学习资源清单

原则：**免费优先，付费只花在刀刃上**。总预算控制在 1000-2000 元。

## 免费资源（主力）

### 第 1-4 周：Python 与工程基础
- [Learn Git Branching](https://learngitbranching.js.org/) — Git 交互式练习
- [Python 官方教程](https://docs.python.org/zh-cn/3/tutorial/) — 语法权威参考
- [菜鸟教程 Python3](https://www.runoob.com/python3/python3-tutorial.html) — 中文速查
- [PEP 8 中文版](https://peps.python.org/pep-0008/) — 代码规范
- [pytest 官方文档](https://docs.pytest.org/) — 单元测试
- [LeetCode 力扣](https://leetcode.cn/) — 每周 2 道简单题（2026-08-29 起，替代原"每天 2 道"）

### 第 5-7 周：LLM 应用开发
- [DeepSeek 开放平台文档](https://platform.deepseek.com/docs) — API 首选（便宜、国内可用）
- [OpenAI API 文档](https://platform.openai.com/docs) — 概念与 Function Calling 权威解释
- [吴恩达 Prompt Engineering 短课](https://www.deeplearning.ai/short-courses/) — Prompt 系统入门
- [鱼皮 AI 知识库](https://ai.codefather.cn) — Vibe Coding 教程、AI 学习路线、130+ 篇实战教程（免费开源）
- [鱼皮 ai-guide 开源仓库](https://github.com/liyupi/ai-guide) — AI 资源大全，可离线阅读

### 第 8-10 周：RAG
- [Chroma 官方文档](https://docs.trychroma.com/) — 向量数据库
- [LangChain 官方文档](https://python.langchain.com/docs) — 检索与编排框架
- [Hugging Face 免费课程](https://huggingface.co/learn) — Embedding/模型原理背景
- [FAISS 官方文档](https://faiss.ai/) — 本地向量检索（第 9 周与 Chroma 对比用）
- [Milvus 官方文档](https://milvus.io/docs) — 生产级向量数据库（第 9 周了解适用场景）
- [GraphRAG 官方文档](https://microsoft.github.io/graphrag/) — 可选：知识图谱检索概念（第 10 周）

### 第 11-13 周：Agent
- [微软 AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners) — 零基础 Agent 课程（免费开源）
- [LangGraph 官方文档](https://langchain-ai.github.io/langgraph/) — Agent 状态图
- [MCP 官方介绍](https://modelcontextprotocol.io/) — 模型上下文协议（第 13 周实操：把工具改造成 MCP Server）
- [Dify 官方文档](https://docs.dify.ai/) — 云版/自部署，第 12 周知识库问答实操
- [Hugging Face PEFT](https://huggingface.co/docs/peft) / [TRL](https://huggingface.co/docs/trl) — 第 13 周 LoRA 微调入门；可参考 [Qwen 微调教程](https://qwen.readthedocs.io/zh-cn/latest/finetuning/)

### 第 14-16 周：工程化
- [FastAPI 官方教程](https://fastapi.tiangolo.com/zh/tutorial/) — 中文文档，后端首选
- [Docker 入门教程](https://docs.docker.com/get-started/) — 容器化部署
- [Streamlit 文档](https://docs.streamlit.io/) — 快速做演示界面
- [Vue 官方文档](https://cn.vuejs.org/) — 可选：前端三选一（第 15 周）
- [ComfyUI 官方文档](https://docs.comfy.org/) — 可选：文生图工作流（第 15 周）
- [vLLM 官方文档](https://docs.vllm.ai/) — 可选：推理性能优化（第 15 周）

### 求职期
- [面试鸭](https://www.mianshiya.com) — 面试题练习（免费部分够用，冲刺期可考虑会员）
- [牛客网](https://www.nowcoder.com/) — 面经与题库
- [Boss直聘](https://www.zhipin.com/) / [拉勾](https://www.lagou.com/) — 主投递渠道

## 付费资源（精挑细选）

| 资源 | 价格 | 什么时候买 | 怎么判断值不值 |
|------|------|-----------|---------------|
| 编程导航会员 | 约 ¥380/年 | 第 5 周 | 主要用途：跟项目、简历写法、求职交流群。**用满 3 天退款期**，内容对自己帮助不大就退 |
| 面试鸭会员 | 约 ¥100-200 | 第 17 周 | 只有进入投递期、确实需要高频刷题时才买 |
| 单门 AI 项目课（如鱼皮 AI 答题平台/AI 代码生成平台） | 约 ¥300-500/门 | 第 8 周后 | 若免费教程的项目跟不动，再选 1 门课跟做；不囤课 |

## 明确不买

- 几万元的"保 offer / 包就业"培训班（割韭菜重灾区）
- 任何"三天速成 AI 开发"的课程
- 超过 2 门的付费课同时进行（会陷入教程地狱）

## 编程导航使用建议（如果买了）

- 优先看：原创项目教程 + 简历写法 + 求职指南 + 交流群
- 不看：囤积资料不学习、把会员当心理安慰
- 平台 AI 知识库是免费的，**先白嫖两周再决定买不买会员**
