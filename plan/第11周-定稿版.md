项目二已经会「先检索再问」。这周解决：**模型要分多步办事时，谁来调用工具**。做法是 Function Calling + 手写最小 ReAct：你定义工具 schema，模型返回要调哪个，**你的 Python 执行**，把结果塞回 messages 再问。检查点 = **不依赖 LangGraph，能讲清循环每一步 messages 里多了什么**。

3. 能用 Thought → Action → Observation 描述这一圈（ReAct），对照 FC 的消息角色
4. 对照项目三：热点抓取 / 赛道筛选 / 写日报 是工具名，本周可以先用假数据，不接真网页
