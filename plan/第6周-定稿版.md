## 一、本周目的

第 5 周你已经能把请求打到模型；这周管 **messages 里写什么**。检查点 = **能解释 prompt 里每一段为什么这样写**（角色 / 任务 / 约束 / 格式），不是堆形容词。

这一周结束时要达到：

1. 能说出四件套：角色、任务、约束（边界）、输出格式
2. 知道少样本（few-shot）和思维链（CoT）各解决什么问题
3. 能要结构化输出（字段齐全的列表或 JSON 思路）
4. 同一任务亲手对比 3 版 prompt，日志记下差异
5. 项目一 `system_prompt.md` 收成 **v1**（人设 + 边界 + 格式），能讲清每个标题存在的理由

**本周不做**：不上 RAG、不改 `main.py` 大结构、不录演示视频（第 7 周）。
