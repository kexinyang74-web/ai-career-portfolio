## 一、本周目的

**从"写脚本"升级到"写程序"**：第 2 周你写出了能跑的脚本，这周开始学**组织代码**——面向对象把数据和操作打包成"类"，模块化让代码能拆能复用；同时第一次**碰真实世界的网络接口**（requests 调公开 API），为第 5 周调大模型 API 做直接铺垫。

这一周结束时要达到 3 个状态：

1. 能用 class 组织代码（self、__init__、方法、继承、dataclass）
2. 能解释"为什么要拆函数/模块"，画出自己的模块结构图
3. 会用 requests 调公开 API，把结果存成 CSV（小脚本 2）

本周不做：不碰 AI/大模型 API（第 5 周开始）、不写业务项目。

## 三、任务清单（含目的与耗时）

### 任务 1：面向对象（Day 15-16）
- 操作：class 定义、__init__ 构造方法、self、实例方法、实例属性/类属性；继承、方法重写、魔术方法（__str__/__repr__）、dataclass
- 资源：Python 官方教程（zh-cn）类部分、菜鸟教程
- 目的：**LeetCode 模板里的 class Solution 就是面向对象**——学了这周，你会瞬间看懂网站模板为什么长那样；第 5 周调 API、写项目全靠类组织
- 预计耗时：2 天
- 产出物：每天的练习代码贴进学习日志

### 任务 2：类型注解/PEP 8/模块 + requests（Day 17-19）
- 操作：类型注解（: int / -> str / List[str]）、PEP 8 规范（命名/缩进/空行）；模块与包（import、__main__）；requests 的 GET/POST、params、headers、超时、状态码、异常捕获
- 目的：第 4 周小脚本 3（CSV/Excel 清洗）、第 5 周 API 调用的直接基础
- 预计耗时：3 天
- 产出物：一个能调通公开 API 的脚本

### 任务 3：每天 2 道 LeetCode 简单题（Day 15-20，共 12 道）
- 操作：数组/字符串/哈希表/双指针标签
- 目的：手感不断档（第 2 周已 12 道，累计 24 道）
- 预计耗时：每天 1 小时
- 产出物：每道题在日志里写一句思路

### 任务 4：小脚本 2——调用公开 API 存 CSV（Day 20）
- 操作：选一个免费公开 API（天气/汇率/排行榜），requests 获取 JSON → 解析 → 存成 CSV
- 目的：本周检查点验收物（模块化 + 网络请求的综合应用）
- 预计耗时：1 天
- 产出物：可运行脚本 + README + 生成的 CSV，推 GitHub
