# 项目三件套规格书

三个项目是简历的核心，也是对抗非科班背景歧视的武器。原则：**一个行业主题贯穿三个项目**，形成"我在某行业落地 AI"的完整叙事。

## 第 0 步：选行业主题（第 1 周完成，1 小时内定）

选你**工作过或最熟悉**的行业，参考：

| 行业 | 项目一示例 | 项目二示例 | 项目三示例 |
|------|-----------|-----------|-----------|
| 电商/零售 | 商品文案助手 | 运营知识库问答 | 竞品价格日报 Agent |
| 教育/培训 | 课程答疑助手 | 教材知识库问答 | 学员学习周报 Agent |
| 金融/财税 | 条款解读助手 | 政策法规知识库 | 政策变更监控 Agent |
| 医疗健康 | 健康科普助手 | 药品/诊疗知识库 | 文献简报 Agent |
| 制造业 | 设备故障排查助手 | 工单知识库 | 生产日报 Agent |
| 法律/咨询 | 合同要点助手 | 案例知识库 | 行业动态日报 Agent |

选完后在项目 README 第一行写明：**"面向 XX 行业的 AI 应用"**。这是你的差异化标签。

## 项目一：行业场景 AI 助手（第 5-7 周）

**定位**：证明你会调 LLM、会做 Prompt 工程。

**必须功能**：
- 通过 API 完成多轮对话（非套壳网页，代码自己写）
- 流式输出开关
- 行业人设系统提示词（角色、边界、输出格式）
- 对话历史管理（清空/保存）
- 错误处理（无密钥、网络失败、API 报错）

**可选加分**：结构化输出（JSON）、自定义参数（temperature）、命令行参数

**验收标准**：
- 本地一条命令可运行
- 能演示 3 种以上"行业内真实场景"提问并得到可用回答
- README 含项目简介、运行方法、示例对话、架构说明

**简历描述要点**：突出"基于 DeepSeek API 独立开发，设计了 XX 行业人设的提示词体系，支持流式输出与错误重试"。

---

## 项目二：行业知识库 RAG 问答（第 8-10 周）

**定位**：证明你会做 RAG，能解决"大模型不懂你的数据"的问题。

**必须功能**：
- 文档加载与切分（20-50 份行业文档）
- Embedding 向量化 + Chroma 持久化存储
- 检索 + 重排 + 引用来源展示
- 30 条人工评测集，回答可接受率 ≥ 70%
- 先 CLI 版，第 15 周补网页界面

**可选加分**：多文档格式支持（PDF/Word/Excel）、元数据过滤、答案评分脚本、FAISS 替代 Chroma 做检索存储（第 9 周对比后可选切换）

**验收标准**：
- 提问能返回"有来源依据"的回答（引用第几篇文档）
- 能讲清切分策略、检索参数为什么这么调
- 演示时对比"没有 RAG"和"有 RAG"的效果差异

**简历描述要点**：突出"构建了 XX 行业知识库问答系统，通过文档切分与向量检索将回答准确率从 XX% 提升到 XX%，并给出引用来源"。

---

## 项目三：行业自动化 Agent（第 11-13 周）

**定位**：证明你会做 Agent，能解决"多步骤真实任务自动化"。

**必须功能**：
- 3 个以上自定义工具（如：网页信息抓取、文件读写、API 查询、计算）
- 工具调用循环（模型选工具 → 执行 → 结果回填 → 继续）
- 自动生成一份完整报告（行业日报/周报）
- 失败处理：工具报错后重试或换策略（自我纠错）
- 日志与成本控制（限制调用次数/token）

**可选加分**：LangGraph 状态图实现、定时触发、发送到邮箱/飞书/微信、接入 1 个 MCP Server（第 13 周）

**验收标准**：
- 连续运行 5 次不中断
- 报告包含数据来源与生成时间，结果真实可用
- README 含架构图（模型、工具、流程的交互关系）

**简历描述要点**：突出"设计并实现了 XX 行业日报自动生成 Agent，串联 3+ 工具完成信息采集-分析-报告全流程，包含自我纠错与成本控制"。

---

## 三个项目的通用要求

- 全部部署上线或"一条命令本地可跑"，README 附演示视频链接（录屏即可）
- 代码规范、有 README、有注释，README 开头放一句"面向 XX 行业"定位语
- 每个项目能用 5 分钟讲完：背景 → 架构 → 难点 → 你的设计决策 → 效果数据
- 不抄袭、不照搬教程：教程里的项目换行业、换功能、加自己的设计，否则面试一问就露馅
