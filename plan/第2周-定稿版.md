## 一、本周目的

**把 Python 语法从"看过"变成"能写"**：本周结束时，要求脱离教程独立写出 100 行以上可运行脚本。

这一周结束时要达到 3 个状态：

1. 基础语法熟练：变量/类型/流程控制/函数/容器（列表、字典、元组、集合）
2. 会文件读写（txt/csv/json）和异常处理（try/except、logging）
3. 完成小脚本 1（批量整理/重命名文件），养成每天 2 道 LeetCode 的习惯

本周不做：不碰 AI/大模型 API、不写业务项目。地基打牢，第 5 周调 API 才不慌。

## 三、任务清单（含目的与耗时）

### 任务 1：Python 基础语法复习（Day 8-10）
- 操作：变量与数据类型、input/print、if/elif/else、for/while、函数定义与调用、字符串方法、列表/字典/元组/集合增删改查
- 资源：Python 官方教程（zh-cn）、菜鸟教程 Python3、PEP 8 中文版
- 目的：语法是所有东西的地基，第 5 周起写 API 调用、RAG 全靠它
- 预计耗时：每天 3-4 小时
- 产出物：每天至少 30 行自己敲的练习代码（贴进学习日志）

### 任务 2：文件读写 + 异常处理（Day 11-12）
- 操作：open/with、read/write、json.loads/dumps、csv 读写；try/except、logging 基础
- 目的：第 4 周小脚本 3（CSV/Excel 清洗）和第 8 周 RAG 文档加载都要用
- 预计耗时：2 天
- 产出物：一个能读 json、写出 csv 的小练习

### 任务 3：小脚本 1——批量整理/重命名文件（Day 13）
- 操作：用 os/pathlib 遍历文件夹，按规则（日期/序号/后缀）批量重命名或归档
- 目的：第 2 周检查点验收物，也是第一个"能解决真实问题"的脚本
- 预计耗时：1 天
- 产出物：可运行脚本 + README 说明，推 GitHub

### 任务 4：每天 2 道 LeetCode 简单题（Day 8-13）
- 操作：数组、字符串、哈希表三个标签，每天 2 道，共 12 道
- 目的：刷题习惯第 2 周就要养成，面试和算法思维双收益
- 预计耗时：每天 1 小时
- 产出物：每道题在日志里写一句思路

### 任务 5：周复盘（Day 13）
