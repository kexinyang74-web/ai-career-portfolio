## 一、本周目的

**从"能写"升级到"写得好"**：第 3 周你写出了结构清晰的程序（函数拆分/模块化），这周学工程化——**环境可复现**（虚拟环境/依赖/配置）、**代码可测试**（pytest）、**代码可调试**（VS Code 调试器）、**命令行操作**（PowerShell）。第 5 周开始调大模型 API，本周的依赖管理、.env 配置、异常与调试能力是直接基础。

这一周结束时要达到的状态：

1. 能用 venv + requirements.txt 让别人一键复现你的环境
2. 能用 pytest 给函数写 5 个以上单元测试
3. 能用 VS Code 调试器断点/单步/看变量
4. 能用 PowerShell 写批量操作脚本
5. 完成小脚本 3（CSV/Excel 清洗 → 统计报告）

**本周不做**：不碰 AI/大模型 API（第 5 周开始）、不写业务项目。

## 三、任务清单（含目的与耗时）

### 任务 1：虚拟环境与依赖管理（Day 22）
- 操作：venv 建环境、激活/退出、pip install/uninstall/freeze、requirements.txt 导出与复现、.env 配置管理（Day 4 学过基础，本周系统化）
- 目的：**环境可复现**——别人拿到你的项目跑得起来；API 密钥等敏感信息进 .env 不进 git
- 预计耗时：1 天
- 产出物：一个带 requirements.txt + .env 示例的小项目

### 任务 2：终端与 shell 基础（Day 23）
- 操作：PowerShell 常用命令（目录/文件/进程/环境变量）、管道（|）与重定向（>）、`Get-ChildItem`/`Where-Object`/`ForEach-Object`；用 PowerShell 写 1 个批量操作小脚本（批量重命名/统计文件）
- 目的：日常开发 80% 操作在终端完成；批量操作不用写 Python 也能做
- 预计耗时：1 天
- 产出物：1 个批量脚本（如给文件夹里所有文件批量改名）

### 任务 3：VS Code 调试器（Day 24）
- 操作：断点、单步执行（Step Over/Into/Out）、变量监视、调用栈；调试一个真实脚本
- 目的：**print 大法升级为专业调试**——出 bug 时能看程序走到哪、变量变没变
- 预计耗时：1 天
- 产出物：用调试器找出并修复一个 bug 的记录

### 任务 4：pytest 测试基础（Day 25）
- 操作：安装 pytest、写测试函数（assert）、跑 pytest、看通过/失败；给小脚本 1/2 的函数补测试（至少 5 个）
- 目的：**代码可测试**——改代码不怕改坏，测试替你盯场
- 预计耗时：1 天
- 产出物：5 个以上通过的测试

### 任务 5：小脚本 3——CSV/Excel 清洗（Day 26-27）
- 操作：读取 CSV/Excel → 清洗（去重/去空/修格式）→ 输出统计报告（csv/openpyxl；pandas 可选装）
- 目的：数据清洗是 AI 应用开发的核心技能之一（训练/调优都离不开干净数据）；本周检查点验收物
- 预计耗时：2 天
- 产出物：可运行脚本 + README + 输出报告，推 GitHub

### 任务 6：LeetCode 每周 2 道（本周首次按新节奏）
- 操作：本周挑 2 道简单题做透（Day 26-27 安排时间）
- 目的：手感不断档，不挤占主线
- 预计耗时：约 2 小时
- 产出物：日志写一句思路
