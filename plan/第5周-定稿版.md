## 三、任务清单（含目的与耗时）

### 任务 1：LLM 核心概念（Day 29）
- 操作：弄清 token、上下文窗口、temperature、top_p、流式输出各自管什么；能画「一次请求」的步骤
- 资源：[DeepSeek API 文档](https://api-docs.deepseek.com/zh-cn/)（Chat Completions）
- 目的：后面调 API 时知道自己在改哪个旋钮，面试能讲清
- 预计耗时：1 天
- 产出物：笔记 + 自测 5 题（概念，不要求当天调通 API）

### 任务 2：注册 DeepSeek 并保管密钥（Day 29 开始，Day 30 必须能用）
- 操作：打开 [platform.deepseek.com](https://platform.deepseek.com) 注册 → 创建 API Key → 复制到**本地** `.env`（项目一或 day30，二选一先有一份即可）。**不要发给我、不要提交 git。**
- 充值：约 10–20 元够学；没额度时调用会 402/余额类错误，到 Day 30 再充也行
- 目的：鉴权 = HTTP 头 `Authorization: Bearer <密钥>`
- 产出物：本机有密钥；`git check-ignore .env` 为忽略

### 任务 3：requests 调 Chat Completions（Day 30-32）
- 操作：`POST {BASE_URL}/chat/completions`，body 含 `model`、`messages`、`temperature`、`stream`
- 单轮：一条 user，解析 `choices[0].message.content`
- 多轮：把上一轮 assistant 内容追加进 `messages` 再发
- 流式：`stream=True`，按行读 `data:`，拼 `delta.content`，直到 `[DONE]`
- 异常：沿用 Day 19 全家桶（Timeout / HTTPError / 401）
- 网络：若 SSL/连接失败，先设代理 `$env:HTTPS_PROXY = "http://127.0.0.1:7897"`（Day 19/20 同一套）
- 模型名：骨架默认 `deepseek-chat`；若控制台/文档已换成别的 ID（如 flash/pro），改 `.env` 的 `MODEL`，以**能 200 为准**
- 预计耗时：3 天
- 产出物：`projects/python-practice/day30`～`day32` 练习脚本

### 任务 4：项目一骨架 → 选题助手（Day 33-34）
- 操作：在 `projects/project-1-ai-assistant` 建 venv、复制 `.env.example` → `.env`、跑 `python main.py`；把 `system_prompt.md` 换成 B站创作者的选题/脚本助手（对照你已定的一句话人设）；README 第一行改成作品定位
- 目的：检查点之外的作品雏形，第 6-7 周继续打磨 prompt
- 预计耗时：2 天
- 产出物：能对话的命令行助手（密钥仍不进 git）
