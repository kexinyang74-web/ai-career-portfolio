## 一、本周目的

第 5–6 周已经能调 API、写 prompt。这周把项目一 **交得出去**：规格书上的必须功能你能演示、README 能让别人跑起来、你能用 STAR 讲这个项目。检查点 = **项目一验收标准全部达成，能脱稿演示**。

这一周结束时要达到：

1. CLI：`/new` `/stream` `/save` 你亲手跑过；错误有提示（无密钥 / 超时 / API 失败）
2. README：简介、如何运行、**选题向**示例对话、架构（system 从哪读、history 怎么走）
3. 至少 3 个行业真实场景提问，回答可用（记进日志或 README）
4. 1 分钟演示（录屏即可；推送等你发话）
5. 项目一简历 STAR **初稿你自己写**

**本周不做**：不上 RAG、不上网页、不改人设定位句、不把密钥写进 README。
