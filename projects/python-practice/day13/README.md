# 批量整理文件工具

> 第 2 周小脚本 1 · 2026-08-26 · 用 pathlib 自动按类型归档 + 重命名文件

## 这个脚本解决什么问题

下载文件夹和桌面总是堆满乱七八糟的文件：照片、文档、压缩包、视频全挤在一起，找一份文件要翻半天。

这个脚本做的事：**扫描一个文件夹 → 按文件后缀（.jpg/.pdf/.zip…）分类 → 自动建子文件夹 → 文件各就各位**。想找什么文件，直接进对应文件夹就行。

## 怎么运行

```bash
# 1. 先造测试数据（生成 10 个乱文件到 test_files/）
python 01_make_test_files.py

# 2. 试跑模式（只演示，不真动文件——确认无误再真跑）
python 06_dry_run.py --dry-run

# 3. 真跑（文件按类型归档，日志写入 file_organize.log）
python 06_dry_run.py
```

## 运行效果

整理前：10 个文件全挤在 `test_files/` 里，后缀五花八门，还有一个没有后缀的。

整理后：

```
test_files/
├── 图片/     ← .jpg、.png
├── 文档/     ← .txt、.pdf、.docx
├── 压缩包/   ← .zip
├── 视频/     ← .mp4
└── 其他/     ← 没匹配到的（比如没后缀的文件）
```

日志文件 `file_organize.log` 记录每一步操作（开始 / 移动 / 完成），出错的也记下来，不会翻车。

## 脚本文件说明

| 文件 | 作用 |
|------|------|
| `01_make_test_files.py` | 造测试数据：生成 10 个乱七八糟的文件，方便练习 |
| `02_scan_files.py` | 遍历文件夹，认识每个文件的名字 / 后缀 / 位置 |
| `03_organize.py` | 核心功能：按后缀分类归档到子文件夹 |
| `04_rename.py` | 进阶：给归档后的文件加序号重命名（01、02…） |
| `05_final.py` | 完整版：归档 + 日志（logging）+ 防出错（try/except） |
| `06_dry_run.py` | 成品：加 `--dry-run` 试跑开关，安全第一 |

## 技术要点（这周学的东西都用上了）

- `pathlib.Path`：现代路径处理，`/` 拼接、`.suffix` 拿后缀
- `RULES.get(suffix, "其他")`：字典的 get 方法，没匹配到归"其他"
- `logging`：5 级日志写文件，排障靠它不靠 print
- `try/except OSError`：单个文件出错不翻车，记日志继续处理
- `--dry-run` 参数：先演示后执行，职业脚本的标准安全开关
