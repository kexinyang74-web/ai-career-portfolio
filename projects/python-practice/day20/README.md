# 小脚本 2：汇率查询 → CSV

从免费公开 API（[open.er-api.com](https://open.er-api.com)）拉取 **166 种货币的实时汇率**，解析出常用币种，存成 CSV 表格。第 3 周收官验收物（模块化 + 网络请求的综合应用）。

## 运行方法

```powershell
python 04_main.py
```

> **网络提示**：直连失败（SSL/ConnectionError 报错）时，先设置代理再运行：
>
> ```powershell
> $env:HTTPS_PROXY = "http://127.0.0.1:7897"
> $env:HTTP_PROXY = "http://127.0.0.1:7897"
> ```
>
> 注意：新开终端窗口后环境变量会失效，需要重设。

## 输出

- **控制台**：成功提示 + 保存的币种数量
- **文件**：`汇率.csv`（UTF-8-sig 编码，Excel 直接打开不乱码）

示例（2026-08-29 数据，数值随行情变化）：

| 币种 | 1 USD 兑换 | 1 币种折合 USD |
|------|-----------|---------------|
| CNY | 6.742068 | 0.148322 |
| JPY | 159.924891 | 0.006253 |
| EUR | 0.861354 | 1.160963 |
| KRW | 1377.942221 | 0.000726 |

## 文件结构（分步学习版）

| 文件 | 作用 |
|------|------|
| 01_test_api.py | 第 1 步：调通 API，看数据结构 |
| 02_parse.py | 第 2 步：解析——字典 → 一行一条 |
| 03_save_csv.py | 第 3 步：存 CSV（utf-8-sig 防乱码） |
| 04_main.py | 完整版：函数拆分 + 异常全家桶（抓 → 解析 → 存） |

`04_main.py` 的结构：

```
main()
 ├── fetch_rates()  抓数据（请求 API）
 ├── build_rows()   解析（字典 → 行列表）
 └── save_csv()     存文件（CSV）
```

## 错误处理

四层异常兜底（04_main.py）：超时 / 连不上 / HTTP 错误 / 其他一切——网络失败时程序不崩，打印是哪一种失败。
