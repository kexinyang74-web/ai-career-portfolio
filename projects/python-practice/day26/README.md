# 小脚本 3:销售数据清洗器(CSV / Excel)

> 第 4 周检查点验收脚本。脏数据 → 清洗(去空格/修格式/去重/丢无效)→ 干净数据 + 统计报告。**CSV 和 Excel 共用同一套清洗代码**——loader 层把两种格式都变成统一的 dict 行。

## 它能干什么

把这种脏数据:

```
2024/1/5, 华东 ,键盘,"¥1,200",2,张伟     ← 区域有空格、金额带符号
2024.1.8,华南,键盘,"¥ 800",2,王芳        ← 日期点分隔
,华东,显示器,,, 陈杰                       ← 关键字段空缺
2024/2/30,华南,键盘,"¥1,000",1,郑爽      ← 不存在的日期
2024/1/20,华东,显示器,"¥3,000",两,王芳   ← 数量是汉字
```

洗成:

```
2024-01-05,华东,键盘,1200.0,2,张伟       ← 日期统一、金额转数字、空格清除
```

再输出:清洗报告(丢了几行、删了几个重复、按区域销售额排名)。

## 目录结构

| 文件 | 职责 |
|---|---|
| `loader.py` | 读文件层:CSV / Excel → 统一的 {列名: 值} 行列表 |
| `cleaner.py` | 清洗层:纯函数,不认识文件格式(可被测试) |
| `main.py` | 流程:读 → 洗 → 写干净文件 → 报告(参数 csv/xlsx) |
| `make_excel.py` | 演示:把脏 CSV 转成脏 xlsx |
| `test_cleaner.py` + `test_loader.py` | 21 个 pytest 测试 |
| `销售数据_脏.csv` | 原始脏数据(故意造的) |

## 环境复现(3 步)

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt     # pytest + openpyxl 等 7 个包
```

## 怎么跑

```powershell
# 1. 清洗 CSV
python main.py csv

# 2. 先造 xlsx 素材,再清洗 Excel(结果与 CSV 版一致,交叉验证)
python make_excel.py
python main.py xlsx

# 3. 跑测试(21 个全绿)
python -m pytest
```

## 产出

- `销售数据_干净.csv` / `销售数据_干净.xlsx`:干净数据(utf-8-sig,Excel 打开不乱码)
- `清洗报告.txt`:统计报告(原始 14 行 → 干净 8 行;按区域销售额 + 合计)

## 清洗规则(清洗一行)

1. 所有字段去首尾空格
2. 金额:去 `¥` `,` `元` → float;转不了(abc)→ 无效行
3. 日期:三种分隔符统一为 YYYY-MM-DD;`2024/2/30` 不存在 → 无效行
4. 数量:纯数字 → int;`"两"` → 无效行
5. 区域/产品/负责人任一为空 → 无效行
6. 整行完全相同 → 去重,只留第一条

## 设计心得(第 4 周工程化三件套的总结)

- **纯函数可测**:cleaner 每个清洗动作是纯函数 → 21 个测试盯场,改代码不怕改坏
- **格式解耦**:loader(读)与 cleaner(洗)分离 → 加一种文件格式,清洗代码零改动
- **utf-8-sig**:写 CSV 永远带它,Excel 打开才不乱码
