# 爆款拆解（一篇一事）

- 平台：B站
- 标题：面试秘籍| 面试时，被问到为什么换行业，怎么回答
- 钩子（开头怎么抓人）：大家好，我是栋哥，今天我们谈的内容是，工作一段时间后想要转行，但是在面试的时候被问到为什么要转行，应该如何回答
- 为什么可能火（3～5 句，写你自己的判断）：
1. 谁会停：干过一阵、正在转行、已经约了面试的人；最怕被问「那你为什么不干原行业了」的人。
2. 别扭在哪：真话容易像逃避（嫌累、嫌钱少、看不上前任），假话又像编。这题一答砸，前面项目经历也会被打折。
3. 手法为这个服务：标题把范围收成这一问，不像空泛「面试技巧」；「秘籍」承诺有现成口径。开头点明「工作一段时间后想转行」，对上已经有旧经历、不是应届空转的人。
