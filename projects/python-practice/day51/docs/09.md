# 爆款拆解（一篇一事）

- 平台：B站
- 标题：【浮生一日】北京程序员的真实一天
- 钩子（开头怎么抓人）：今天是程序员的真实一天，我是早上凌晨三点半起床，超级困，到了这个小区，遇到两只大狗，一下就精神了。时间差不多了，我们上楼吧
- 为什么可能火（3～5 句，写你自己的判断）：
1. 谁会停：想看程序员真实日常的人；考虑转行、或对「北京码农一天到底什么样」好奇的人；吃「浮生一日」这类跟拍的人。
2. 别扭在哪：网上要么把程序员说成轻松高薪，要么说成纯加班惨。观众缺的是可核对的一天，不是鸡汤或吐槽。
3. 手法为这个服务：标题用「真实一天」立下承诺；开头不讲薪水和技能，先甩凌晨三点半起床、困、小区两只大狗——具体、不像演的，才会想把这一天看完。
- 和转行/读书/减肥的关系（可选）：转行
