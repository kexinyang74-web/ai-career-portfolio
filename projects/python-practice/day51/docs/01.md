# 爆款拆解（一篇一事）

- 平台：B站
- 标题：别再假装努力学习！费曼：真正的记忆，从来不是输入而是输出
- 钩子（开头怎么抓人）：费曼能够记住30年前读过的方程式，姓名、日期、脚注乃至一切细枝末节，他都能像一个人从厨房抽屉里随手取物那样从脑海深处精准的抽离出来。
- 为什么可能火（3～5 句，写你自己的判断）：
1. 谁会停：假装很努力、却记不住的人（自学、备考、转行补课都算）。
2. 别扭在哪：标题把「输入很多」说成假装努力，和日常习惯对着干。
3. 手法为这个服务：费曼 +「30 年」让「输出才叫记住」显得可信；抽屉比喻让抽象记忆变成能想象的画面。
- 和转行/读书/减肥的关系（可选）：读书
