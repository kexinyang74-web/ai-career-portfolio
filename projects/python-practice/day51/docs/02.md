# 爆款拆解（一篇一事）

- 平台：B站
- 标题：30岁转行程序员？晚吗？搞编程还有戏吗？40岁码农聊聊
- 钩子（开头怎么抓人）：30岁学编程晚不晚，也有人问25岁学编程晚不晚，如果是25岁的话还不晚。
- 为什么可能火（3～5 句，写你自己的判断）：
1. 谁会停：谁会停：卡在「是不是太晚了」的人，尤其 30 岁前后想转程序员的；已经在写代码的人，也可能冲着「40 岁码农」进来对年龄。
2. 别扭在哪：标题连问三次「晚吗 / 还有戏吗」，把不敢问出口的焦虑摊开；开头先把 25 岁划成「还不晚」，30 岁的人会更急着听下文怎么判自己。
3. 手法为这个服务：30、25、40 不是装饰，是把「晚」从抽象感觉变成具体岁数；「40 岁码农聊聊」用比观众更「晚」的人出镜，让「还有戏」比较好信。
- 和转行/读书/减肥的关系（可选）：转行
