# 爆款拆解（一篇一事）

- 平台：B站
- 标题：大体重减肥9周跟练1.0 | 必瘦10斤+ | 200斤欢迎光临
- 钩子（开头怎么抓人）：这套跟练视频是为大重量膝盖脆弱运动能力差，特别容易来到减肥瓶颈期的各位男女胖胖们量身定制的
- 为什么可能火（3～5 句，写你自己的判断）：
1. 谁会停：体重大、大约 200 斤上下、想减又不敢跟普通操的人；膝盖发虚、运动能力差、已经卡在瓶颈的人。
2. 别扭在哪：市面上很多跟练默认你能跳、能跪、能撑。大体重一跟就怕伤，减不动又容易自责。标题直接说「200 斤欢迎光临」，等于先把「这套不是给你的」挡回去。
3. 手法为这个服务：「9 周」「必瘦 10 斤」把结果收成可核对的数字；开头点名大重量、膝盖脆弱、运动能力差、瓶颈期，用「量身定制」对上这拨人，而不是空喊加油。
- 和转行/读书/减肥的关系（可选）：减肥
