# 爆款拆解（一篇一事）

- 平台：B站
- 标题：从0做出你的第一个App ｜ 零基础AI编程保姆教程
- 钩子（开头怎么抓人）：这期视频我会手把手带你用AI做出你的第一个APP。全程假设你没有任何编程和AI的基础
- 为什么可能火（3～5 句，写你自己的判断）：
1. 谁会停：想做 App、但不会写代码、也不懂 AI 的人；已经会一点的人可能进来验货，但不是这条的主目标。
2. 别扭在哪：想动手又怕教程默认你会编程。「从 0」「零基础」「保姆」把门槛按到最低，标题等于在说：你不会，也能跟完第一个 App。
3. 手法为这个服务：开头直接宣布「手把手」「假设你没有任何编程和 AI 基础」，把承诺说到具体动作上，不像空喊「适合小白」。
- 和转行/读书/减肥的关系（可选）：AI应用
