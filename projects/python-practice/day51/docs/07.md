# 爆款拆解（一篇一事）

- 平台：B站
- 标题：10分钟有效缓解肩颈酸痛僵硬 每天一遍告别不良体态 （坐姿拉伸+自我按摩）
- 钩子（开头怎么抓人）：Hello,我是范李猿，做过舞蹈演员也做过运动员，今天是自我按摩系列的肩颈篇，可以有效的预防和缓解，肩颈最容易出现的僵硬酸痛以及像是 头前伸圆肩驼背还有富贵包等等这样的体态问题。
- 为什么可能火（3～5 句，写你自己的判断）：
1. 谁会停：久坐后肩颈僵、酸、抬头费劲的人；对着镜子觉得头前伸、圆肩、驼背、富贵包的人。
2. 别扭在哪：知道体态差，却没空去健身房、也不想先搞懂一堆理论。痛是每天的，动作如果不能「坐着就做」，很难坚持。
3. 手法为这个服务：「10 分钟」「每天一遍」「坐姿拉伸+自我按摩」把承诺收成可执行的一小段；开头用舞蹈演员、运动员身份撑住「有效」；点名头前伸、圆肩、驼背、富贵包，对得上观众已经在嫌的部位。
- 和转行/读书/减肥的关系（可选）：减肥
