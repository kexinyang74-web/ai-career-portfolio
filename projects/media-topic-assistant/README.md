# 灵感小记 · 自媒体选题助手

一个本机运行的中文网页：聊真实经历 → 生成选题卡片 → 展开策划单 → 收藏、记录创作状态。

默认面向22—26岁、毕业0—3年的年轻人，以AI工具为主，学习成长、生活管理为辅；主平台为小红书图文，单篇投入约4小时。可在「账号定位」中修改。

## 在 Windows 启动

需要 Python 3.11 或以上版本。

1. 双击 `start.cmd`，首次会创建项目自己的 `.venv`、安装依赖并生成 `.env`。
2. 用文本编辑器打开项目内的 `.env`，在 `DEEPSEEK_API_KEY=` 后填写你的 **DeepSeek 官方 API 密钥**。不要把密钥发送到聊天里。
3. 如果服务已启动，按 Ctrl+C 停止，然后再次双击 `start.cmd`。
4. 浏览器打开 <http://127.0.0.1:8765>。启动窗口需保持运行；Ctrl+C 停止服务。

也可在本项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

已安装依赖时可直接运行：

```powershell
python -m uvicorn app:create_app --factory --host 127.0.0.1 --port 8765
```

若端口被占用，停止之前的本应用窗口；手动运行时也可选择别的端口。不要将监听地址改为 `0.0.0.0`，本版没有登录系统。

## 怎么使用

- 聊2—4轮，告诉助手遇到的问题、试过什么、还有什么没做。每次追问一个问题，也可以随时「现在生成」。未发送的草稿会提示你先发送。
- 默认6张卡片，允许5—10张。看中某个题目就展开为策划单，包含待验证观点、亲测步骤和待补素材，不直接生成正文。
- 点击「感兴趣／不适合」，可填写原因并点击「保存反馈」。重新推荐会参考这些反馈；同一对话内已否定的标题会被程序过滤，角度差异还需人工判断。
- 收藏后默认「待创作」，在收藏夹改为「已发布／放弃」。取消收藏不会删除选题；历史记录保留各轮结果。点击「新对话」开始另一个主题。
- 消息先保存，再调用模型。超时或失败后点击「重试回复」，不会重复写入同一条消息。选题生成失败不会清空上一轮。策划单已生成后，再打开不会重复调用模型。

## DeepSeek 与联网查证

默认模型 `deepseek-flash`，可在 `.env` 的 `DEEPSEEK_MODEL` 修改。仅使用官方 `https://api.deepseek.com/responses`，不接入第三方付费服务。

**联网能力有实际限制：**截至本次实现查阅的[官方兼容说明](https://api-docs.deepseek.com/guides/responses_api/)，当前模型会忽略内置 `web_search`；与早期文档片段不同。因此项目不承诺官方搜索当前可用：

- 选题包含产品功能、费用等外部事实时才尝试官方搜索工具。
- 必须同时收到已完成的 `web_search_call` 和真实 `url_citation` 才接受来源；模型自行写出的 URL 不算证据。
- 未返回搜索证据时显示「未核实」，仍保留选题；同一进程缓存工具不可用状态，避免每轮重复探测。策划单里的「重新查证」可手动再次探测。
- 有来源仍标为「有参考来源，待核实」，不会声称功能或效果已被证实。重新查证失败会保留已有参考资料；链接、查证时间和对应选题一起保存。
- 未配置密钥时可浏览网页、编辑定位及查看已有内容，不能进行AI对话或生成。错误提示不回显服务商原始响应和密钥。

## 数据与文件

对话、账号定位、选题、策划单和来源关联保存在 `data/assistant.db`（SQLite）；重启恢复。停止服务后复制整个 `data` 文件夹可备份。

**本机保存不等于离线推理**：生成时会将账号定位、当前对话及相关选题反馈发送给 DeepSeek；按需查证会向其发送相关事实。请使用脱敏素材。密钥仅从后端环境读取，浏览器不接收密钥；`.env`、`data/`、虚拟环境和测试截图已排除在 Git 外。

- `app.py`：本地API、流程与结构校验；`models.py`：输入和模型输出结构。
- `store.py`：SQLite持久化；`provider.py`：DeepSeek调用、错误映射及来源证据验证。
- `static/`：原生网页，无前端构建流程、无外部字体/CDN。
- `tests/`：后端回归、模拟服务商故障、真实浏览器自动化。

## 测试

在本项目目录执行：

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m playwright install chromium
python tests/browser_check.py
```

测试使用临时数据库及模拟模型，不使用真实密钥、不收费。浏览器测试监听本机18765端口，结束自动关闭；截图写到忽略的 `test-results/`。

真实模型联调和「每轮至少2个愿意做」需你在配置密钥后用3组真实经历完成，记录表见 [ACCEPTANCE.md](ACCEPTANCE.md)。自动化测试通过不代表选题质量已经人工验收。
