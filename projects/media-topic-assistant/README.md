# 灵感小记 · 自媒体创作工作台

一个本机运行的中文网页，贯通 **定位 → 素材 → 选题 → 策划 → 图文与视频脚本 → 制作 → 发布登记 → 复盘**。八个助手共用资料，图文和视频各自保留稿件、进度与发布数据。

首页为创作工作台；原选题助手保留在 [/topics](http://127.0.0.1:8765/topics)。从选题卡或工作台的收藏选题直接创建作品。原有默认定位作为未确认草稿导入，可以重新定位，不会导入学习计划里的个人叙事。

## 先完成一篇内容

1. **账号定位**：填写经历访谈，生成三个候选，选择采用后编辑并保存；也可以直接手动填写。受众、目标、语气、栏目、出镜意愿、平台、内容方向比例和每周预算都可改。每次保存形成定位版本。
2. **素材库**：记录亲身经历、外部参考或待验证想法，标注来源与待补信息。可附加 PNG/JPEG/WebP 图片（每张最大8MB），图片仅保存预览，AI只读你的文字说明。案例拆解分析提供的文字，不能只凭链接声称读过原文。
3. **选题池／作品库**：从收藏选题创建作品，或手动填题目；勾选关联素材，添加图文、口播、录屏教程、生活记录、混合视频中的一种或多种形式。
4. **创作编辑室**：设置模板、页数（默认6）或视频秒数（默认180），生成策划与稿件。也可以直接粘贴已有稿件保存人工版本。跨形式改编时选择目标形式及参考稿件。
5. **改稿与制作**：逐段编辑或让AI局部修改；确认版本后仍可另存新稿。选择稿件生成标题、封面文字、发布介绍和制作说明，再生成并调整SOP任务。文字可导出Markdown，结构化逐页稿／分镜和任务另有CSV。
6. **本周工作台**：按账号每周预算安排未排期任务。自动排期遵循同一形式的任务顺序，超出预算则延后；可手动调整截止日期、预计和实际耗时。已有手动排期不自动覆盖。
7. **发布与复盘**：手动完成设计、拍摄、剪辑与平台发布，再登记平台、日期、观察天数、数据、评论与感受。生成单篇或周期复盘，明确采纳的新问题会回到选题收藏。

可以跳过前置步骤，直接写稿或登记发布。缺少依据时AI应写“待补／待亲测”，不能把草稿当作已完成的亲测结论。图文生成校验页数；视频生成校验分段预计时长，允许目标的10%误差（短视频至少3秒容差）；实际朗读和剪辑时长仍需你复核。

## 数据与版本约定

- 作品保留创建时的定位快照。后续修改账号不改变旧作品。
- 每次生成或保存修改都创建新稿件版本；旧稿件、确认状态和生成所用的文字素材快照可保留。图文／视频状态独立。
- 相同操作编号与内容的重试只保存一次；相同编号配不同内容会被拒绝。模型失败不清空已有稿件。
- 更新程序后第一次启动会自动升级SQLite，在数据库旁建立 `assistant.pre-studio-1.db`。重试迁移另建带随机后缀的新备份，迁移本身在事务内完成，失败回滚。
- 日常备份：停止服务后复制整个 `data` 文件夹，包含数据库、升级备份与 `studio-images` 图片目录。恢复到旧版程序时使用升级前备份；不要把新数据库直接交给旧版程序写入。
- 数据为空表示未记录，不当作零。周期复盘按平台、内容形式与观察天数分组；缺指标不计算均值，小样本仅提出待验证假设。

无密钥时仍可使用手动定位、素材、写稿、版本、任务排期、发布登记与导出；AI候选、分析、生成和复盘需要配置密钥。首版不包含自动绘图、配音、剪辑或平台发布。

## 在 Windows 启动

日常使用可以双击桌面的 **灵感小记 · 创作助手** 快捷方式（指向项目内 `Start-Studio.cmd`）。它会复用已经运行的新版服务；未运行时在后台启动，并自动打开浏览器。关闭网页不会停止后台服务。启动日志在 `data/launcher/`；更新后若仍运行旧服务，请先关闭旧服务再启动。首次安装仍按以下步骤运行 `start.cmd`。

需要 Python 3.11 或以上版本。

1. 双击 `start.cmd`，首次会创建项目自己的 `.venv`、安装依赖并生成 `.env`。
2. 用文本编辑器打开项目内的 `.env`，在 `DEEPSEEK_API_KEY=` 后填写你的 **DeepSeek 官方 API 密钥**。不要把密钥发送到聊天里。
3. 如果服务已启动，按 Ctrl+C 停止，然后再次双击 `start.cmd`。
4. 浏览器打开 <http://127.0.0.1:8765>。启动窗口需保持运行；Ctrl+C 停止服务。

也可在本项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

已安装依赖时可直接运行：

```powershell
python -m uvicorn app:create_app --factory --host 127.0.0.1 --port 8765
```

若端口被占用，停止之前的本应用窗口；手动运行时也可选择别的端口。不要将监听地址改为 `0.0.0.0`，本版没有登录系统。

## 原选题助手怎么使用（/topics）

- 聊2—4轮，告诉助手遇到的问题、试过什么、还有什么没做。每次追问一个问题，也可以随时「现在生成」。未发送的草稿会提示你先发送。
- 默认6张卡片，允许5—10张。看中某个题目就展开为策划单，包含待验证观点、亲测步骤和待补素材，不直接生成正文。
- 点击「感兴趣／不适合」，可填写原因并点击「保存反馈」。重新推荐会参考这些反馈；同一对话内已否定的标题会被程序过滤，角度差异还需人工判断。
- 收藏后默认「待创作」，在收藏夹改为「已发布／放弃」。取消收藏不会删除选题；历史记录保留各轮结果。点击「新对话」开始另一个主题。
- 消息先保存，再调用模型。超时或失败后点击「重试回复」，不会重复写入同一条消息。选题生成失败不会清空上一轮。策划单已生成后，再打开不会重复调用模型。

## DeepSeek 与联网查证

默认模型 `deepseek-flash`，可在 `.env` 的 `DEEPSEEK_MODEL` 修改。仅使用官方 `https://api.deepseek.com/responses`，不接入第三方付费服务。

**联网能力有实际限制：**截至本次实现查阅的[官方兼容说明](https://api-docs.deepseek.com/guides/responses_api/)，当前模型会忽略内置 `web_search`；与早期文档片段不同。因此项目不承诺官方搜索当前可用：

- 选题包含产品功能、费用等外部事实时才尝试官方搜索工具。
- 必须同时收到已完成的 `web_search_call` 和真实 `url_citation` 才接受来源；模型自行写出的 URL 不算证据。
- 未返回搜索证据时显示「未核实」，仍保留选题；同一进程缓存工具不可用状态，避免每轮重复探测。策划单里的「重新查证」可手动再次探测。
- 有来源仍标为「有参考来源，待核实」，不会声称功能或效果已被证实。重新查证失败会保留已有参考资料；链接、查证时间和对应选题一起保存。
- 未配置密钥时可浏览网页、编辑定位及查看已有内容，不能进行AI对话或生成。错误提示不回显服务商原始响应和密钥。

## 数据与文件

对话、账号定位版本、选题、素材、作品、稿件、任务、发布与复盘保存在 `data/assistant.db`（SQLite）；重启恢复。图片在 `data/studio-images`。

**本机保存不等于离线推理**：AI操作会把相关定位、文字素材、所选稿件、对话或复盘数据发送给 DeepSeek；按需查证会发送相关事实。图片附件不发送。请使用脱敏素材。密钥仅从后端环境读取，浏览器不接收密钥；`.env`、`data/`、虚拟环境和测试截图已排除在 Git 外。

- `app.py`：本地API、流程与结构校验；`models.py`：输入和模型输出结构。
- `store.py`：SQLite持久化；`provider.py`：DeepSeek调用、错误映射及来源证据验证。
- `static/`：原生网页，无前端构建流程、无外部字体/CDN。
- `tests/`：后端回归、模拟服务商故障、真实浏览器自动化。
- `studio_api.py`、`studio_service.py`：新工作台HTTP接口、生成上下文与SOP。
- `studio_store.py`、`studio_models.py`：升级、数据关联、版本与校验。
- `studio_prompts.py`、`studio_exports.py`：八助手规则及Markdown/CSV导出。
- `static/workbench.*`：新工作台网页；原 `static/index.html` 与 `app.js` 服务选题入口。

## 测试

在本项目目录执行：

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m playwright install chromium
python tests/browser_check.py
python tests/studio_browser_check.py
```

测试使用临时数据库及模拟模型，不使用真实密钥、不收费。浏览器测试各自启动临时服务并在结束后关闭；截图写到忽略的 `test-results/`。请不要将测试截图视为真实模型质量验收。

真实模型联调、「每轮至少2个愿意做」及图文/视频实际可制作性需你在配置密钥后用3组真实经历完成，记录表见 [ACCEPTANCE.md](ACCEPTANCE.md) 与 [STUDIO_ACCEPTANCE.md](STUDIO_ACCEPTANCE.md)。自动化测试通过不代表真实生成质量已经人工验收。
