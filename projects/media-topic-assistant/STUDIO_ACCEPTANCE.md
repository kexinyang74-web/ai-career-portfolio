# 工作台验收

## 已自动覆盖的行为

运行 `python -m pytest -q`，以及 `python tests/browser_check.py`、`python tests/studio_browser_check.py`。

后端覆盖：旧数据升级、回滚和重试备份；新旧定位页面兼容；账号与素材快照；请求幂等；五种内容形式；图文页数与视频预计时长；局部修改不影响其它段；人工稿件；生成失败保留旧稿；图片附件；任务顺序和预算；发布数据缺失值；分组复盘；新问题回流；Markdown/CSV导出。

浏览器使用临时数据库和模拟模型，验证真实按钮、表单、错误提示、刷新持久化和390像素布局。测试不使用真实API密钥、不发平台、不改个人数据。

## 用户真实样稿验收（尚待填写）

使用你愿意提供给模型的三组真实素材，每组同时生成一份图文稿：

| 素材 | 视频形式 | 图文可制作 | 视频可制作 | 未编造经历或结果 | 需要修改的地方 |
|---|---|---|---|---|---|
| 一次真实的学习／工作问题 | 知识口播 | 待验收 | 待验收 | 待验收 | |
| 一次工具的实际操作记录 | 录屏教程 | 待验收 | 待验收 | 待验收 | |
| 一段生活变化的真实过程 | 生活记录 | 待验收 | 待验收 | 待验收 | |

逐篇确认：

- 定位和语气像你，内容对目标读者有一个明确用途。
- 图文逐页内容完整；视频的台词、镜头和操作对应。实际朗读后调整时长。
- 未做过的测试和未拍摄的镜头明确列为待补，没有把参考资料写成你的经历。
- 包装中的标题与正文一致；制作清单可以直接交给自己设计、拍摄和剪辑。
- 保存确认稿后继续修改，旧版本仍可找到、导出。
- 发布以后使用同样的观察天数登记数据；空指标保持空，复盘提出可执行的小实验。

不以浏览量、粉丝数或“爆款”承诺作为软件验收结果。
